# 审批批内危险度分层标记(审批疲劳纵深)

> 日期:2026-09-26 · 状态:已落地(真机目检待大仙)
> 上游:能力盘点 `docs/research/client-capability-gap-analysis.md`(P1-4;审批疲劳=自动驾驶点 Approve,高普遍度)

## 目标

审批线已按轮成批(治「逐条审」),但批内文件同权重 —— 用户仍可能无脑整批通过。本变更给批内文件加危险度分层:敏感路径(凭据/Shell 配置/CI/服务定义)红标「高危」,提示细读 diff 再放行。

## 范围边界

| 面 | 做 | 不做(去向) |
|---|---|---|
| 判定 | 纯函数 classifyRisk:路径正则白名单(保守 14 条:凭据/Shell rc/CI/服务定义),宁漏勿扰 | 学习式/统计式打分;按内容判危(读 diff 判敏感=高成本高误报) |
| 呈现 | 文件行「高危」红徽标 + tooltip 提示 | 整批阻断/高危二次确认(摩擦设计,先验标记价值);批头汇总徽标(随二期) |
| 生效面 | 审批线批审阅文件节(BatchFileSection) | 批审阅单(BatchSheet)复用 —— 同纯函数,二期接入 |

## 方案取舍

| 决策 | 选定 | 否决与理由 |
|---|---|---|
| 规则形态 | 常量正则表 + classifyRisk 纯函数(单测钉) | 用户自定义规则面(设置项)——规则面未经验证,先内建收敛 |
| 判定对象 | 仓库相对路径(审批线 events 归因既有面) | 绝对路径——家目录相对形态不一,规则集会翻倍 |
| 词目 | 「高危」+ tooltip 全句 | 「危险」等恐吓词——定位是提醒不是拦截 |

## 风险

| 风险 | 对策 |
|---|---|
| 误报致红标通胀 | 规则刻意窄(14 条,全系统级);`environments/` 目录名等不误伤(测试钉) |
| 漏报 | 宁漏勿扰纪律;正则表后续按误报/漏报反馈增删 |

## 验证

- 门禁:`pnpm typecheck && pnpm test && pnpm check:arch-boundary && pnpm check:file-size && pnpm build` + react-doctor 100。
- 单测:`risk.test.ts`(凭据/Shell/CI/服务命中;业务文件与目录名近形不误伤;批内汇总)。
- 真机:造一个含 `.env` 与普通文件的批次 → 高危徽标与 tooltip,由大仙目检。
