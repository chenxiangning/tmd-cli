# 跨引擎一键接力(撞墙不停摆)

> 日期:2026-09-26 · 状态:已落地(真机目检待大仙)
> 上游:能力盘点 `docs/research/client-capability-gap-analysis.md`(P0-2 动作半件;预警半件已随 notify 插件落地)

## 目标

「撞墙即停摆 + 换引擎全靠手工重贴 prompt」(盘点 §2.3,高普遍度)。本变更给当前会话一个命令入口:选目标引擎 → 预览/编辑接力提示词 → 新引擎开新会话(同 cwd/工作区)并自动发出,进度不停摆。

## 范围边界

| 面 | 做 | 不做(去向) |
|---|---|---|
| 摘要 | 确定性拼装:最近 10 条用户 prompt + 源引擎/标题/模型行;可预览可编辑 | AI 生成摘要(引入模型调用与延迟,二期评估);助手正文解析 |
| 目标 | 其余全部 CLI profile(十引擎同窗的独有优势) | 跨工作区接力(先同 cwd);远程 SSH 会话作源(cliSessionId 语义不同,后议) |
| 入口 | 命令 `session-relay.to-engine`(抽屉/改键) | 会话 tab 右键菜单项——那是外壳静态契约,扩它 = 新 kernel 贡献面,等价值验证后再议 |
| 发送 | createSession → writeSession(摘要,新会话首条消息,走轮次闸正常开轮) | 静默注入(绕过 promptGate=破坏轮次语义) |

## 方案取舍

| 决策 | 选定 | 否决与理由 |
|---|---|---|
| 摘要生成 | 用户消息枚举 + 模板拼装(确定性) | 让 AI 总结——撞墙时源会话往往已不可用,且引入成本/延迟;用户消息本就是「进度」的最可靠回忆键 |
| 预览编辑 | textarea 全文可改,默认即发 | 直接静默发送——接力质量取决于摘要质量,人必须在环 |
| 目标过滤 | 全部其他 CLI profile | 按额度水位自动推荐/排序——额度数据按凭据覆盖不齐,不猜 |
| Shell/SSH 会话 | 命令对 shell 会话静默 no-op | shell 无 CLI 语义可接 |

## 风险

| 风险 | 对策 |
|---|---|
| 摘要丢关键进度(只有用户输入) | 文案引导用户在编辑框补写;N=10 可后续配置化 |
| 新会话尚未就绪即写入 | createSession 返回即 PTY 就绪(spawn 契约);writeSession 是唯一写入口(锚定+Ask 解除语义齐全) |
| 目标引擎未装/启动失败 | createSession 抛错原样展示在对话框,不吞 |
