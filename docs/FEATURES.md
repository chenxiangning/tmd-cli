## 工作区会话

- 添加工作区(目录选择器),工作区即会话容器;持久化 `~/.tmd-cli/workspaces.json`(列表 + 激活项,Rust 侧临时文件 + rename 原子写)
- 默认工作区兜底:列表缺失时自动补建 `~/.tmd-cli/default` 于首位,删除后重启重建
- 工作区卡片:双态文件夹图标 + 名称 + Default badge
- 工作区 hover 动作组:切到主区 / 刷新会话(重扫磁盘历史) / 新建会话菜单
- 工作区右键菜单与「+」等效;行双击同为折叠 toggle
- 工作区折叠/展开:单卡 toggle + 全部折叠/展开按钮,折叠态持久化;未设置过折叠态的工作区默认折叠
- 删除工作区:新建会话菜单「工作区操作」组,仅剩一个时不可删
- 新建会话菜单:按 CLI 列出(portal + fixed 定位,视口内夹取),每个 CLI 行带单项刷新按钮
- 会话模型:一个会话固定一个 CLI(profile + PTY + cwd + CLI 原生 session id),不可中途切换
- 会话恢复:由各 CLI profile 声明 resumeArgs,适配 CLI 自身会话存储
- 磁盘会话打开回退:CLI 未声明 resumeArgs 时以 profile 默认启动参数打开(等同新会话)
- 会话列表:活会话固定在所属 CLI 分组顶部,组内按时间倒序
- 磁盘历史:各 CLI 插件 listSessions 扫描,带相对时间
- 磁盘历史分页:初始条数 + 「更多」翻倍加载(默认 10 条起步)
- 身份去重:已绑定的磁盘会话不在历史区重复出现;重复打开已有活 PTY 的磁盘会话直接聚焦,在途单例闸防重复 spawn
- 身份绑定守护:一个 CLI 磁盘身份只准一个活会话持有(fail-closed),并行 spawn 老会话优先 10s 认领窗
- 身份绑定主路径内容自证:候选磁盘文件自证 id/cwd/createdAt,cwd 不符剔除、创建时刻离 spawn 最近者胜;插件未声明自证才退 mtime 水位 + 复活文件仲裁
- 会话时间轴:贯穿竖线 + 状态节点三态呼吸灯(绿=对话中 / 蓝=完成未读 / 灰=静止)
- 呼吸灯首写闸:用户首写前的输出(spawn 横幅/resume 回放/重绘)不亮灯、不结算未读;终端协议回传(焦点/鼠标/查询应答)照写 PTY 但不算用户输入
- 蓝色未读:组内置顶,点开查看即消
- 会话行右键菜单:复制 Session ID / 重命名 / 置顶 / 删除
- 行内扎点开关:hover 显形、已扎常亮,一键置顶到全局或取消(置顶到工作区内走右键菜单)
- 未落盘活会话:重命名与置顶入口置灰(覆盖层以 CLI 磁盘身份为 key)
- 会话重命名:应用侧覆盖层标题,不改 CLI 磁盘文件
- 会话标题自愈:活会话绑定磁盘身份即触发重扫补扫(omp 实证懒落盘晚于 spawn 35s+);身份巡航不依赖激活态,后台会话文件落盘即绑
- 磁盘标题解析:omp title 记录 > session 行字段 > claude summary 行 > 首条用户消息,折叠空白 60 字截断,XML 包装与指令注入不计入
- 置顶标题快照:只存真标题(短码兜底不入库);快照缺失或为历史短码垃圾时读磁盘解析并回填,标题链 = 手动命名 > 原生标题/快照 > 短码
- 置顶双作用域:置顶到全局 / 置顶到工作区内,当前作用域 ✓ 标记,点击迁移或取消
- 置顶投影:工作区置顶固定组顶不参与分页;全局置顶汇入侧栏顶部「已置顶」区
- 全局置顶区:段折叠 localStorage 持久化;点击直达活会话否则按原工作区恢复;已删工作区/未注册 CLI 的残留置顶不渲染但数据保留;右键菜单无删除项
- 删除会话:两步确认(首击武装再击执行),物理删除磁盘 jsonl 并顺带清理命名与置顶覆盖层
- 会话列表显示预算:总数(1–100,默认 20)按 CLI 分组均分(向下取整,尾数不补),已配额组按配额(显式 0 = 不露出)
- 预算弹窗:总数编辑行 + 每注册 CLI 一行配额;非法提交拒绝并回退;清空配额回均分;剪除已卸载 CLI 残留 key;修改即时生效
- 预算为独立可插拔插件 session-budget:经工作区标题行挂载点贡献入口,拔出回默认分页、重插恢复预算数值
- 活动守望:内核单点结算会话活动状态(对话中/完成未读/静止);轮次静默 >2s 结算一轮,绿灯判活窗口同 2s;未读与呼吸灯为纯内存态,随 PTY 消亡
- PTY 生命周期:spawn / read / write / resize / kill,双线程聚合泵(reader + emitter:8ms 合批窗、单批 1MB 上限、64 深有界队列回压子进程)
- PTY 命令线程纪律:spawn/write/kill 一律 spawn_blocking 后台线程(spawn 冷路径内联 PATH 富化,kill 含子进程回收),不占 Tauri 主线程
- 新会话默认 120×32,注入 TERM=xterm-256color 与 COLORTERM=truecolor(会话 env 可覆盖);resize 幂等,尺寸未变不重发 SIGWINCH
- 幕布尺寸自适应:ResizeObserver 跟随分栏拖动/侧栏折叠/窗口缩放自动 fit 并下发 PTY resize,每次重挂载必发一次尺寸同步
- 写入隔离:每会话独立写锁 + 后台线程执行,单会话阻塞写不冻结 UI、不波及其他会话
- PTY 输出解码:跨聚合批暂存不完整 UTF-8 尾部与下批拼接再解码,仅真坏字节替换 U+FFFD
- 会话输出落盘:64MB 旋转日志(截头保留尾部 32MB,偏移锚点不受截头影响)+ 幕布往前翻页读取(每页 512KB,页起点对齐转义序列/UTF-8 边界);日志布局 `~/.tmd-cli/session/<引擎>/<项目slug>/<会话id>.log`
- 会话日志降级:日志创建/写入失败不阻塞终端输出,仅「加载更早的输出」翻页能力关闭
- 历史重写输入闸:回放/翻页整段重写窗口内丢弃终端查询应答,陈旧回传不注入 PTY、不误开首写闸
- 会话退出清理:输出日志随退出删除,退出不区分正常/异常,内核统一移除会话并广播消亡(Rust 侧自清理兜底 webview reload 错过 exit)
- 顶栏会话 tab 条:中央同时展示最多 4 个已打开会话,点击切换、活跃高亮,超容挤掉最早打开的 tab(会话不受影响)
- tab 标题与会话列表同优先级(手动命名 > 打开时捕获快照 > 短码),改名即时生效;未读会话带未读点
- tab × 仅摘除不杀会话:摘活跃 tab 自动切剩余最近打开的,摘尽回欢迎页;会话消亡同步剪除;tab 列表不持久化
- tab 次序稳定:次序 = 打开次序,重复聚焦已打开会话原位不动(防跳动),仅新会话追加队尾
- 会话标题 tab 条可在设置/外观页整体关闭(sessionTabsEnabled,默认开)
- 输出缓冲分块(上限可配,5 万–1000 万字符,默认 50 万)与字节流安全截断(转义序列/UTF-16 代理对对齐)
- 会话输出常驻订阅:spawn 起即入内核缓冲,与幕布挂载无关;切换会话重挂载经缓冲整段回放,切回不黑屏不重载
- 近期会话:欢迎页展示磁盘最近会话,可快速进入

## Ask 等待确认与提示音

- Ask 等待确认检测:内核单点检测 PTY 输出中 CLI 阻塞等待确认的界面标记(跨分片 / 夹杂 ANSI 均可命中)
- Ask 标记来源:内核硬编码正则(omp Ask 面板 / 通用选择页脚 / y-n 提问 / claude 权限句式),非 CLI profile 声明
- Ask 页脚窗口:标记只认剥 ANSI 后的末 5 行,原始尾巴按 1024 字符跨分片拼接;标记滚出页脚(正文/历史帧残留)不触发
- Ask 检测候选确认:首击仅立候选不亮不响,标记复现且距首击 ≥1.2s 才升级等待;16KB 内无复现撤销候选
- 等待确认标签:会话列表行(含全局置顶区活会话)显示绿色胶囊,用户作答立即清除,会话消亡一并清理
- 作答复燃抑制:写入后 8s 内已答面板残影重绘不亮标不响铃;输出静默 2s 且页脚已无面板标记即自愈摘除残签;终端协议回传同样清候选/标签并起算 8s 抑制窗(真面板持续重绘可再升级,自愈兜底)
- 重绘去重:同一未答提问反复出现不重复广播事件
- Ask 提示音:检测命中播放,每次等待一段最多一次(状态边沿),作答后新一轮提问再次播放
- 轮次结束提示音:turnSettled 后 3s 延迟确认播放(声音资产懒加载,不进主 chunk)
- 提示音播放管线:4 音效 wav 懒加载 + 结果缓存(失败逐出,下次播放重试),加载/播放失败静默吞错不影响会话;「试听」与事件播放共用同一管线,结束音复用零重复资产
- 多会话并发提示:各会话独立状态边沿、无跨会话去抖,多会话同时等待确认各播一次;结束音确认也按会话各自排程
- 结束提示音门槛:仅未查看轮次排程;3s 复查时已读/有新输出/会话移除/新结算均静默放弃
- 后台提醒:窗口失焦时激活会话完成一轮也计未读(标蓝 + 结束音),切回窗口恢复已读,默认开
- 提示音配置:设置页行为 tab,Ask 开关(默认开)+ 内置音效选择(默认/风铃/铃声/叮咚)+ 「试听」按钮,即时持久化
- 结束提示音配置:行为 tab 独立开关(默认开)+ 音效选择(共用内置 4 音效)+ 「试听」按钮
- 提示音设置兼容:非法值回落默认,旧配置无损加载

## 对话框(Composer)

- 富输入 textarea,发送快捷键可配置(Enter 发送/Shift+Enter 换行,或 ⌘/Ctrl+Enter 模式互换)
- IME 组词期所有按键(Enter/↑↓/Tab/Esc)不拦截,全部交给输入法
- 空输入 ↑↓ 焦点移交幕布(判定序:IME 组词 / 候选下拉 / 非空输入均不移交,纯空白视同空);幕布获焦后方向键原生透传给 CLI
- 触发符 `@`:文件/文件夹引用,候选来自磁盘目录列举(150ms 防抖 + 60s 目录缓存,上限 20 条)
- 触发符 `/`:命令候选,由 CLI profile 声明,CLI 自己解析
- 触发符 `$`:技能候选,由 CLI profile 声明,不支持则不激活
- 触发下拉键盘导航:↑↓ 选择 / Enter / Tab / Esc,选中替换触发符 + token;失焦自动收起,面板点击不抢输入焦点
- 发送编排:translate 钩子处理语法差异(如 `$skill` → `/skill:skill`),与手动输入同一发送路径,不拦截不解析;仅翻译小写字母开头 token,$HOME/$100 等原样透传
- 多行文本直发,CR 提交;pi 系 CLI 正文包 bracketed paste 序列防吞回车
- 图片拖入/粘贴:粘贴仅收图片、拖入收任意文件,落盘临时文件 → 注册附件 → 输入框注入 `@path `;文件树拖入项目内文件/文件夹直接引用原路径,不落临时副本
- 附件条:展示/删除/重排(上限 12 个);图片附件自动生成缩略图,点击放大预览;删附件同步删 `@path` 文本,删文本同步移除附件
- 附件条头部「全部清除」:一键清空全部附件并同步移除输入框对应 `@path` 文本
- 拖拽悬停视觉:accent 内环 + 虚线遮罩;全局护栏:文件拖出 composer 不触发 webview 导航
- 只读状态工具栏:当前会话模型 + 思考强度,读各 CLI session JSONL,2 秒轮询,不可识别显示 `—`,不可交互;未观测到落盘数据前显示 CLI 默认值并标「默认」角标
- Quota 额度 chip:composer 工具栏额度指示,点击弹详情弹窗(各窗口用量/下次刷新时间/余额,可手动刷新)
- 额度查询:7 类供应商 HTTP 协议适配(kimi/minimax 中英/智谱中英/deepseek/openai-codex)+ 未知中转站探测;codex 官方 OAuth 读本地 rollout 快照零 HTTP;claude 官方订阅无公开 API,提示到 CLI 内 /usage 查看;自定义 key 按 base_url 检测供应商
- 额度供应商识别含阿里云百炼 Coding Plan:dashscope base_url 明确标记无公开额度 API,提示到控制台查看,不误入未知中转站探测
- Quota chip 模型路由:切换模型即作废旧供应商数据按新模型重抓,乱序/过期抓取按模型标签丢弃;同模型刷新失败保留上次成功数据仅标警示
- 凭据引用:`$ENV_VAR` 只读解析(仅 *_KEY/*_TOKEN/*_SECRET 与 QUOTA_*/PI_* 白名单放行),`!command` 拒绝执行
- 命令抽屉:⌘/Ctrl+K 开合,右上角开关按钮,Esc 关闭(rail × 同),点外不自动关,无活跃会话置灰;↑↓ 移动 + Enter 激活
- 命令抽屉分区:命令 / 技能 / MCP / 插件,分区按声明派生,只渲染有数据的分区 + 「全部」聚合;左缘竖排图标 rail 切换(顶部关闭、底部计数),高度自适应内容
- 命令抽屉动作:send 直接发送(经 translate,toast 回显实际发送文本并延迟收起)/ insert 光标处插入(缺省),插件分区项点击切换对应面板
- 命令抽屉运行时发现:listSuggestions 声明优先,失败或返回空回退静态表,60s TTL 缓存
- 命令抽屉图标:候选可声明语义图标;声明了但未收录回退通用图标,完全未声明才回退 kind glyph
- 命令抽屉复位与焦点:每次打开重置回「全部」分区、选中归零、焦点驻留抽屉;关闭即归还焦点到 composer 输入框;插件分区无对应右栏面板的条目回退打开设置面板
- 对话框高度四段可调(70/30/20/10%),工具栏 ↑↓ 逐级展开/收起
- 消息锚点栏:composer 右缘用户消息 dash 导航,按栏高实测容量抽样分桶
- 锚点数据来源:用户消息由 CLI profile readSessionUserMessages 声明,内核仅活跃会话 2s 轮询、按 id 增量合并;无订阅者停表,会话消亡清缓存
- 锚点 hover 预览卡:序号 + 首行摘要;点击定位 xterm buffer 平滑滚动(目标不在 buffer 时逐页回翻最多 12 页);active 逐帧追踪
- 锚点定位失败:超出 12 页回翻仍不可达时,该 dash 闪烁 1.2s 提示未命中
- 发送事件:发送路径广播 prompt 事件(供审批线归批,text 截 400 字)

## 审批线

- 批次定义:一轮对话(相邻两条用户消息之间)的所有 AI 文件改动为一个批次
- 零变更轮不占时间线:纯阅读轮不产生账本条目;events 净零轮(写了又写回原样)落空 turn 行封口关闭该轮,写入轨迹留 edit 行可审计;批次序号 = 真实轮次,缺号可见
- 双归因:CLI profile 声明 editMarks(写入事件标记)或 readSessionEdits(会话磁盘事件流)→ events 归因(事件路径由 AI 写入事件行定死);两者皆无 → 回退 git 窗口推断(批次标「推断」提示可信度);events 会话的 shell 落盘(cp/脚本/重定向,无事件)按同一套窗口推断补充进批 —— 仅补全账本无事件行的路径,事件路径永不被并行窗口抢走;非 git 工作区维持纯事件语义
- 记账失败不阻塞发送:锚点落账失败 1.5s 后台重试一次,再失败本轮变更并入下一轮窗口兜底;写入事件落账失败 1s 后重试一次
- 写入事件检测:内核 EditWatch 扫 PTY 流(剥 ANSI、跨分片行拼接),路径按会话 cwd 归一,逃逸/家目录拒绝;宁漏勿误;同轮同路径只报一次,用户写入即开新轮清集
- events 归因 4s 轮询 CLI 会话文件,水位线增量落账;早于本轮锚点的迟到事件直接丢弃,防串轮
- 磁盘事件流时序:落锚点前先拉净上一轮尾巴再记账,结算前先尾拉一轮再封口;水位线首见取当前时刻,防应用重启后历史事件全量回放灌入死锚点
- 流式记账:AI 写入事件到达即落账(edit 行:路径 + 前像副本 + 首拍快照 + 次数),封口前轨迹可审计;封口后事件(回放/重绘)丢弃
- 前像三级解析:① anchor 基线拷入 sidecar blob;② 基线不可知时链取同路径最近未退批的批后像(按路径级回退感知跳过已退路径,中途轮已删该文件即截断);③ 链也不可得 = 真新建(A);跨轮既有文件不误记 A;用户仓库之后 gc/重置不影响账本
- 批次状态机:open → pending → approved / reverted / done(全部失配自动转 done);pending 与 approved 可回退
- 封口可修订:结算后、下一锚点前的继续改动以修订追加进同一批,读取以最后一行为准;变更集完全相同的重复封口不落冗余行
- 审批语义:通过(approve)为纯标记,不动任何文件;动作集 = 回退 / 应用 / 反悔 / 通过标记;与 git 插件零耦合
- 状态合成优先级:全部失配的自动已处理优先于通过标记;已退批拒绝再通过标记
- 应用(apply):按账本批后像精确写回磁盘(回退的镜像,仅已退批可应用);live 偏离批前像即跳过,绝不静默覆盖;二次确认,执行前守卫照例落账(但反悔通道对应用批不可达:全量应用批回待审被状态闸拒,撤销应用的正路是再次回退)
- 部分回退/部分应用按路径累计:回退全部路径处理完(含失配跳过)才转已退,应用全部完成批回待审;批内删除的文件无应用语义,显式列出跳过
- 审批时间线面板(右栏):批次倒序,批次行 = 序号 + prompt 摘要 + 引擎/模型 + 文件数 ±stats + 状态徽标 + 时间 + 归因标记(推断批显式提示)
- 面板数据流:批次清单挂载期间 6s 轻轮询;进行中批 diff 按 live 工作区现算并 6s 定时强刷,封口批直读账本固化 diff 零重算
- 面板摘要行:当前项目名 + 待审批批数(只计非进行中的待审批)
- 清单刷新失败保留旧批次不清空,错误横幅可点击重试,与「本会话还没有批次」空态严格区分
- 文件行常驻展开,逐文件状态字母 chip + AI 写入次数 ×N(events 归因)
- 点击批次/文件行 → 中央开批审阅单 tab(一批一个 tab,文件行深链滚动高亮)
- 批审阅单:用户消息卡(截 4000 字)+ 引擎/模型/思考强度/轮耗时元信息 + AI 修改的文件分区(状态 chip + 路径 + ± + 着色 diff,默认展开可折叠)
- 批审阅单动作面:工具条只露出通过 + 回退整批(带可退计数),单文件回退走文件分区头 hover(仅 pending 且 live 未失配);应用/反悔只在时间线批尾;占位三态(会话已结束 / 非 git 无审批数据 / 与批后像无差异)
- 回退整批 / 只回退此文件:回退前自动打恢复点(guard,只抓被触碰路径,单文件 8MiB 上限);守卫在写盘前先落账,回退前已不存在的路径记无内容、反悔时对其执行删除;守卫不依赖用户 git,非 git 工作区同样可用
- 反悔:仅整批已退可反悔(后端状态闸拒绝其余态,部分回退批不露出);成功后批回待审、回退路径集清空、守卫清除(不可二次反悔,再退需重新生成新守卫);按守卫副本直接写回,不做 live 内容比对(手改文件会被覆盖回退前一刻)
- 确认纪律:回退/应用共用内联二次确认卡;反悔无确认直接按守卫副本写回
- 回退冲突:文件被手改即跳过并显式列出,绝不静默覆盖
- 自动已处理:文件已提交或内容偏离批次后像 → 逐文件标记,全部失配批次自动转 done
- 陈旧标记:内容已变的文件行内标记,不可回退仍可看 diff
- 快照上限:单文件超 8MiB、符号链接、合并冲突只记状态不存内容(skip 原因随账本留存)
- 二进制文件不出 diff 文本:前 8000 字节含 NUL 判定二进制,只记状态与零行统计
- 会话严格绑定:审批线生命周期 = 单个会话,新会话从零开始,其他会话批次不可见;events 事件路径无 mtime 仲裁,并行会话零误归(shell 落盘补充路径走 mtime 窗口仲裁)
- git 归因并行仲裁:文件 mtime 落在哪个锚点窗口就归谁,窗口重叠时最近提示者赢;mtime 不可得(删除态/时钟异常)回退外会话已封口认领
- 身份自愈:首条 prompt 以 tmd 会话 id 起链,CLI 磁盘身份绑定后账本自动回填;身份被多活会话争持时先创建者保留、后到者回退 tmd id 起新链
- 强退恢复:面板首挂代封上一运行遗留的开放锚点(60s 新鲜度宽限);超 30 分钟未封口锚点由记账路径自动代封
- 非 git 工作区:events 归因会话照常记账/回退/应用(提交态不可推导,live 只有 same/changed 两档);git 归因维持仅 git 工作区
- 快照机制:影子对象库(裸仓库只写 blob 不建 commit),永不触碰用户仓库 index/refs;存储于 `~/.tmd-cli/checkpoints/{md5(cwd)}/`(objects.git + ledger.jsonl + states.json)
- states.json 只存审核覆盖(approved/reverted 标记 + 回退路径集 + 守卫 id + 原因),done 由清单现场推导不落盘
- 快照清理:prune 按保留条数(100 批)+ TTL(30 天)清账本,并对对象库做 reachability 清理(未被保留条目引用的 blob 直删,对象库不再单调增长)
- prune 细节:各会话未封口的最新锚点及其 edit 行随批保留,悬空批次审核态一并清理;面板挂载/切换工作区时按工作区触发一次,同工作区每运行不重复

## Git 面板

- 单视图三段:差异 / 分支 / 历史,外观对齐 codemoss(契约见 `openspec/changes/git-right-panel/`)
- 勾选文件 + 写消息 + 提交一次完成;commit 执行权仅面板按钮,composer `/commit <msg>` 仅预填
- commit 消息:3 行高输入可多行,无长度上限与历史记忆,前后端各 trim 一次;提交成功清空消息/勾选/amend 并收起抽屉
- amend 提交:勾选后可零选文件改写上一提交,保留原 author、更新 committer
- 空提交防线:tree 无变化拒绝提交,提交信息空白拒绝;提交签名 git config → 环境变量 → 兜底 tmd-cli@localhost
- 差异视图:libgit2 patch 生成,前端 LRU 缓存 50 条/20MB;平铺/树形切换
- 视图切换:差异/分支/历史下拉切换,含「Git Graph」禁用占位(后续版本);平铺/树形选择为进程内存,重启回默认
- 重命名检测:status 与 diff 双轨开启 rename 检测,文件可标 R、patch 携带旧路径(find_similar 默认 50% 相似度配对)
- 暂存/取消暂存/丢弃(stage/unstage/discard,discard 走 checkout_index 不经 fs 删除,前端 confirm 前置)
- 文件行内动作:hover 显形 +/−(按暂存态切换 stage/unstage)与 ↺(仅有工作区改动时出现);文件从清单消失时自动摘除其勾选与展开
- discard 语义 = 还原到暂存区(已暂存内容保留、untracked 不动);stage/unstage/discard 路径纵深校验,拒绝绝对路径与 `..` 分量
- 冲突文件:状态标 C,禁勾选/暂存/丢弃,引导到幕布终端解决后提交
- 未跟踪文件显示 U,可勾选提交,整文件按新增计入 diff 与行数统计
- 特殊仓库形态:detached HEAD 显示 detached@<短sha>;空仓库(unborn)分支名取 HEAD symbolic ref,可直接完成首个提交,历史返回空表、ahead/behind 记零
- 差异聚合行:当前分支 → 上游分支、聚合增删行数、变更文件总数
- ahead/behind 独立低频拉取:挂载/分支变化/写操作后/⟳ 全量刷新时执行,不挂 5s 轮询
- patch 抽屉:二进制文件仅提示不展开;纯暂存文件预览暂存侧(HEAD→index),含工作区改动才预览工作区侧(即勾选提交的实际内容),无手动切换
- patch 抽屉展开行为:同时只展开一个文件(再点收起);高度封顶 288px 内部滚动;原始 unified diff 直渲无行号(+/− 行着色,hunk 头 accent 色)
- 刷新机制:状态 5s 轮询(失焦暂停)+ 聚合行数 60s 慢巡航;幕布外改动签名感知自动作废 diff 缓存;顶栏 ⟳ 全量刷新;切换工作区整桶清空 patch 缓存并收起抽屉
- 分支:列举 / 切换 / 新建 / 删除;当前分支拒删,未合并分支双击后二次点击强制;切分支 safe 模式不覆盖脏工作区
- 新建分支:分支视图顶部内联输入行(非弹层),Enter 或 + 提交、基于当前 HEAD;空仓库拒绝(先完成首个提交),重名拒绝
- 分支列表:本地/远程分组带计数,远程分支只读展示,origin/HEAD 符号引用不入列,按末次提交时间倒序,行悬停显上游或末次提交摘要;行点击即切换,当前分支行不可点(checkout 目标=当前幂等成功)
- 历史 log 浏览:每页 50 条,滚动距底 48px 自动翻页,时间+拓扑双排序保证分页稳定
- 历史条目:短 sha + 摘要 + 相对到天时间(今天/昨天/N 天前/N 个月前/N 年前),悬停显作者名/邮箱与完整时间;条目纯展示不可点(commit 详情留待 Graph);空消息显「(空消息)」,翻到底显「已到最早提交」
- 远端:面板一键 fetch(--all --prune)/ pull(尊重 pull.rebase 配置,显 behind 计数)/ push(ahead>0 显现);300s 总超时到点中止,禁终端凭据提示;ssh 未自配 core.sshCommand 时才注入 BatchMode + ConnectTimeout=10(自配不覆盖);凭据失败引导幕布终端
- 错误契约:五类 E_* 前缀直传前端剥壳展示;非 git 目录显空态;凭据失败引导幕布终端执行
- 后端 Repository 句柄缓存:per-cwd FIFO 上限 16,写操作成功后主动失效,下次访问重开保新鲜

## SSH 远程

- SSH 一等会话(russh 0.62.2 + russh-sftp 2.3 引擎):输出走 `pty://out/{id}` 同构事件,幕布/tab 条/输出缓冲/翻页全链路复用;SSH 会话无 composer,不参与 Ask 检测/审批线/状态栏
- 认证矩阵:password / privateKey(PEM 清洗 + passphrase + 路径展开)/ keyboard-interactive 多轮(上限 5 轮,密码类提示自动代答);私钥认证失败自动回落 KBI;KBI 被禁且允许密码时走密码回落提示
- known_hosts:`~/.tmd-cli/ssh_known_hosts.json`(host+port → SHA256 指纹);首连/变更弹信任卡(120s 超时 = 拒绝),设置页可重置信任
- 断线重连:keepalive 30s×3 探活,3 次退避重连(2/5/10s,单次 20s 超时),连接代际失效 SFTP/转发通道;重连失败会话退出(不复活)
- 代理:每主机可配 HTTP CONNECT / SOCKS5(手写握手,支持用户名密码),配错快速失败不静默直连
- 右栏 SSH 面板:连接卡(状态呼吸点/延迟探测 15s 轮询/断开)+ 端口转发段 + SFTP 远端文件树(懒展开)
- 本地端口转发(`-L`):127.0.0.1 绑定,本地端口留空自动分配(49152+),占用预检,点击复制地址,会话关闭级联停止
- SFTP:与终端同连接开 subsystem(不重认证);右键菜单下载/上传/新建目录/重命名/递归删除;传输进度条 + 取消
- 远端文件编辑:点击文件开编辑器 tab(CodeMirror),读 200KB 上限分页,写回带 mtime+size 乐观并发,冲突弹覆盖确认,⌘S/按钮保存,脏标记
- 主机管理:设置页 SSH 分区,主机 CRUD(留空保留旧凭据)+ `~/.ssh/config` 扫描导入(Host/HostName/User/Port/IdentityFile 解析,私钥 PEM 校验内联,重复标灰)+ known_hosts 重置;凭据明文随 settings.json 落盘(用户裁决,spec 记录风险)
- 新建入口:新建会话菜单「SSH 连接…」(workspace.newSessionMenu 挂载点)→ 主机选择 overlay → 建会话挂当前工作区
- 会话列表:SSH 活会话独立分组(kind 判断),标题取主机名,右键断开
- 插件可拔(feature 类):拔出 = 菜单入口/右栏面板/设置分区/overlay 全下电,引擎会话随应用退出消亡

## 网络代理

- 「网络代理」浮层:滑动块开关 + 代理地址(http/https/socks5/socks5h,默认 http://127.0.0.1:7890,启用态空地址回落默认),校验/归一后落 settings
- 提交与校验:开关切换即时生效,地址 blur/Enter 提交;校验失败 inline 报错不落盘,Rust 侧 reqwest 同构兜底校验;落盘/加载时 trim 去控制字符
- 生效:Rust proxy.rs 进程 env 注入(HTTP(S)_PROXY/ALL_PROXY 大小写共 6 变量),覆盖客户端联网与之后 spawn 的 CLI 子进程;已在跑的旧会话需手动重启才走代理
- 关闭:恢复启动时继承的 env 快照(还原用户 shell 原有代理);NO_PROXY 与继承值合并追加 localhost,127.0.0.1,::1
- 拔出插件 = 浮层断电且功能下电(数值保留;Rust 读 settings.disabledPlugins,重启后 env 不再注入,开关为开也视同关)
- 入口:侧栏齿轮菜单 / 底栏钉住按钮,经事件总线唤起,壳与插件互不引用
- 浮层交互:Esc / 点背板 / 右上角 X 关闭;锚点右侧优先弹出,视口边距夹取
