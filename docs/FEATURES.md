# tmd-cli 功能清单

> 需求变更验收总文档。按域分组,一行一个功能点,不做关联。

## 工作区会话

- 添加工作区(目录选择器),工作区即会话容器
- 工作区卡片:双态文件夹图标 + 名称 + Default badge
- 工作区 hover 动作组:切到主区 / 刷新会话(重扫磁盘历史) / 新建会话菜单
- 工作区右键菜单与「+」等效
- 工作区折叠/展开:单卡 toggle + 全部折叠/展开按钮,折叠态持久化
- 新建会话菜单:按 CLI 列出,portal + fixed 定位
- 会话模型:一个会话固定一个 CLI(profile + PTY + cwd + CLI 原生 session id),不可中途切换
- 会话恢复:由各 CLI profile 声明 resumeArgs,适配 CLI 自身会话存储
- 会话列表:活会话固定在所属 CLI 分组顶部,组内按时间倒序
- 磁盘历史:各 CLI 插件 listSessions 扫描,带相对时间
- 磁盘历史分页:初始条数 + 「更多」翻倍加载(默认 10 条起步)
- 会话时间轴:贯穿竖线 + 状态节点三态呼吸灯(绿=对话中 / 蓝=完成未读 / 灰=静止)
- 呼吸灯首写闸:用户首写前的输出(spawn 横幅/resume 回放/重绘)不亮灯、不结算未读
- 蓝色未读:组内置顶,点开查看即消
- 会话行右键菜单:复制 Session ID / 重命名 / 置顶 / 删除
- 会话重命名:应用侧覆盖层标题,不改 CLI 磁盘文件
- 会话标题自愈:活会话绑定磁盘身份即触发重扫补扫(omp 实证懒落盘晚于 spawn 35s+);身份巡航不依赖激活态,后台会话文件落盘即绑
- 置顶标题快照:只存真标题(短码兜底不入库);快照缺失或为历史短码垃圾时读磁盘解析并回填,标题链 = 手动命名 > 原生标题/快照 > 短码
- 置顶双作用域:置顶到全局 / 置顶到工作区内,当前作用域 ✓ 标记,点击迁移或取消
- 置顶投影:工作区置顶固定组顶不参与分页;全局置顶汇入侧栏顶部「已置顶」区
- 删除会话:两步确认(首击武装再击执行),物理删除磁盘 jsonl
- 会话列表显示预算:总数(1–100,默认 20)按 CLI 分组均分,已配额组按配额(显式 0 = 不露出)
- 预算弹窗:总数编辑行 + 每注册 CLI 一行配额;非法提交拒绝并回退;清空配额回均分;剪除已卸载 CLI 残留 key;修改即时生效
- 预算为独立可插拔插件 session-budget:经工作区标题行挂载点贡献入口,拔出回默认分页、重插恢复预算数值
- 活动守望:内核单点结算会话活动状态(对话中/完成未读/静止)
- PTY 生命周期:spawn / read / write / resize / kill,双线程聚合泵
- 会话输出落盘:64MB 旋转日志 + 幕布往前翻页读取
- 输出缓冲分块(上限可配)与字节流安全截断
- 近期会话:欢迎页展示磁盘最近会话,可快速进入
- 顶栏会话 tab 条:顶栏中央同时展示最多 4 个已打开会话,点击切换、× 摘除不杀会话(摘活跃 tab 自动切到剩余最近打开的);打开次序稳定,超限挤除最老;完成未读缀蓝点(设计见 `superpowers/specs/2026-09-03-session-title-tabs-design.md`)

## Ask 等待确认与提示音

- Ask 等待确认检测:内核单点检测 PTY 输出中 CLI 阻塞等待确认的界面标记(跨分片 / 夹杂 ANSI 均可命中)
- 等待确认标签:会话列表行(含全局置顶区活会话)显示绿色胶囊,用户作答立即清除,会话消亡一并清理
- 重绘去重:同一未答提问反复出现不重复广播事件
- Ask 提示音:检测命中播放,每轮(以输出静默为界)最多一次,新一轮确认再次播放
- 轮次结束提示音:turnSettled 后 3s 延迟确认播放(声音资产懒加载,不进主 chunk)
- 提示音配置:设置页行为 tab,开关(默认开)+ 内置音效选择(默认/风铃/铃声/叮咚)+ 试听按钮,即时持久化
- 提示音设置兼容:非法值回落默认,旧配置无损加载

## 对话框(Composer)

- 富输入 textarea,发送快捷键可配置(Enter 发送/Shift+Enter 换行,或 ⌘/Ctrl+Enter 模式互换)
- 触发符 `@`:文件/文件夹引用,候选来自文件树
- 触发符 `/`:命令候选,由 CLI profile 声明,CLI 自己解析
- 触发符 `$`:技能候选,由 CLI profile 声明,不支持则不激活
- 触发下拉键盘导航:↑↓ 选择 / Enter / Tab / Esc,选中替换触发符 + token
- 发送编排:translate 钩子处理语法差异(如 `$skill` → `/skill:skill`),与手动输入同一发送路径,不拦截不解析
- 多行文本直发,CR 提交
- 图片拖入/粘贴:落盘临时文件 → 注册附件 → 输入框注入 `@path `
- 附件条:展示/删除/重排;删附件同步删 `@path` 文本,删文本同步移除附件
- 拖拽悬停视觉:accent 内环 + 虚线遮罩
- 只读状态工具栏:当前会话模型 + 思考强度,读各 CLI session JSONL,2 秒轮询,不可识别显示 `—`,不可交互
- Quota 额度 chip:composer 工具栏只读额度指示
- 额度查询:7 类供应商 HTTP 协议适配 + 未知中转站探测;codex/claude 官方 OAuth 优先本地快照零 HTTP;自定义 key 按 base_url 检测供应商
- 凭据引用:`$ENV_VAR` 只读解析,`!command` 拒绝执行
- 命令抽屉:⌘/Ctrl+K 开合,右上角开关按钮,Esc 关闭(rail × 同),点外不自动关,无活跃会话置灰
- 命令抽屉分区:命令 / 技能 / MCP / 插件,分区按声明派生,只渲染有数据的分区 + 「全部」聚合;左缘竖排图标 rail 切换(顶部关闭、底部计数),高度自适应内容
- 命令抽屉动作:send 直接发送(经 translate,toast 反馈并收起)/ insert 光标处插入(缺省),插件分区项点击切换对应面板
- 命令抽屉运行时发现:listSuggestions 声明优先,失败回退静态表,60s TTL 缓存
- 命令抽屉图标:候选可声明语义图标,未收录回退 kind glyph
- 消息锚点栏:composer 右缘用户消息 dash 导航,超长抽样分桶
- 锚点 hover 预览卡:序号 + 首行摘要;点击定位 xterm buffer 平滑滚动;active 逐帧追踪
- 发送事件:发送路径广播 prompt 事件(供审批线归批)

## 审批线

- 批次定义:一轮对话(相邻两条用户消息之间)的所有 AI 文件改动为一个批次
- 双归因:CLI profile 声明 editMarks(写入事件标记)→ events 归因(账本只记 AI 写过的文件);未声明 → 回退 git 窗口推断(批次标「推断」提示可信度)
- 写入事件检测:内核 EditWatch 扫 PTY 流(剥 ANSI、跨分片行拼接),路径按会话 cwd 归一,逃逸/家目录拒绝;宁漏勿误
- 流式记账:AI 写入事件到达即落账(edit 行:路径 + 前像副本 + 首拍快照 + 次数),封口前轨迹可审计;封口后事件(回放/重绘)丢弃
- 前像自足副本:事件首击时把 anchor 基线内容拷进 sidecar blob;基线不可知(非 git 工作区)时链取同路径最近未退批的批后像,跨轮既有文件不误记 A;用户仓库之后 gc/重置不影响账本
- 批次状态机:open → pending → reverted / done;pending 唯一可回退
- 审批语义:通过 = 什么都不做,回退是唯一动作;与 git 插件零耦合
- 应用(apply):按账本批后像精确写回磁盘(回退的镜像,仅已退批可应用);live 偏离批前像即跳过,绝不静默覆盖;二次确认 + 执行前打守卫可反悔
- 审批时间线面板(右栏):批次倒序,批次行 = 序号 + prompt 摘要 + 文件数 ±stats + 状态徽标 + 时间 + 归因标记(推断批显式提示)
- 文件行常驻展开,逐文件状态字母 chip + AI 写入次数(events 轨迹);resume 断档线,断档前批次只读
- 点击批次/文件行 → 中央开批审阅单 tab(一批一个 tab,文件行深链滚动高亮)
- 批审阅单:用户消息全文卡 + AI 修改的文件分区(状态 chip + 路径 + ± + 着色 diff,默认展开可折叠)
- 回退整批 / 只回退此文件:回退前自动打恢复点(guard,只抓被触碰路径)
- 反悔:reverted 批可恢复回来,按回退路径定向恢复
- 回退冲突:文件被手改即跳过并显式列出,绝不静默覆盖
- 自动已处理:文件已提交或内容偏离批次后像 → 逐文件标记,全部失配批次自动转 done
- 陈旧标记:内容已变的文件行内标记,不可回退仍可看 diff
- 会话严格绑定:审批线生命周期 = 单个会话,新会话从零开始,其他会话批次不可见;events 归因无 mtime 仲裁,并行会话零误归
- 非 git 工作区:events 归因会话照常记账/回退/应用(提交态不可推导,live 只有 same/changed 两档);git 归因维持仅 git 工作区
- 快照机制:影子对象库(裸仓库只写 blob 不建 commit),永不触碰用户仓库 index/refs;与 git 工作区最终变更是两套
- 快照清理:prune 按保留条数 + TTL 清账本,并对对象库做 reachability 清理(未被保留条目引用的 blob 直删,对象库不再单调增长)

## Git 面板

- 单视图三段:差异 / 分支 / 历史,外观对齐 codemoss(契约见 `openspec/changes/git-right-panel/`)
- 勾选文件 + 写消息 + 提交一次完成;commit 执行权仅面板按钮,composer `/commit <msg>` 仅预填
- 差异视图:libgit2 patch 生成,前端 LRU 缓存 50 条/20MB;平铺/树形切换
- 暂存/取消暂存/丢弃(stage/unstage/discard,discard 走 checkout_index 不经 fs 删除)
- 分支:列举 / 切换 / 新建 / 删除;历史 log 浏览
- 远端:fetch / pull / push shell-out(300s 总超时,免终端凭据提示);ahead/behind 计数

## 文件与编辑器

- 文件树:单层懒展开,隐藏过滤,目录排前
- 文件树右键:新建文件 / 新建文件夹 / 重命名 / 移入废纸篓 / 在访达中显示;写操作全经 Rust fs_edit(绝对路径,禁 .git 段,写上限 16MB)
- 文件树行 hover「在访达中显示」快捷按钮
- 中央 tab 文件编辑器:CodeMirror 6 可写编辑 + 保存,语言包按扩展名动态加载
- 预览高亮:highlight.js;文件图标/颜色经 fileVisual provider 注册点
- Markdown 预览:GFM + 数学(KaTeX)+ Mermaid 图 + 本地图片(asset 协议)+ 图片查看器 + 大纲侧栏 + 图片/Mermaid 全屏

## 设置与外观

- 设置面板:overlay 常驻,section/tab 经 settingsRegistry 注册表扩展
- 外观 tab:主题跟随系统/亮/暗 + 21 个 VS Code preset 网格(内核 theme 引擎,--tmd-* token 派生) + 会话标题 tab 条开关(默认开)
- 行为 tab:发送快捷键模式(Enter 发送 ↔ ⌘/Ctrl+Enter 发送互换)、Ask 提示音开关与音效、会话输出缓冲上限
- 设置持久化 `~/.tmd-cli/settings.json`,sanitize 归一,非法值回落默认
- 插件拔插状态(disabledPlugins)同落 settings,重启生效

## 插件市场(插排)

- 插排 / 清单双视图,17 个注册插件可视化插拔,写 settings.disabledPlugins,重启生效(运行期不热卸载)
- core 类焊死不可拔(composer / settings / welcome);engine / feature 可拔
- 插件徽标:CLI 引擎用品牌字形,功能插件用 lucide 语义图标独立彩色(设计定稿见 superpowers/specs/2026-09-03)

- 凭据盘点:已登录供应商凭据与额度一览(覆盖 omp/pi/codex/claude/grok;kimi/qoder 未覆盖)

## 网络代理

- 「网络代理」浮层:滑动块开关 + 代理地址(http(s)/socks5),校验/归一后落 settings
- 生效:Rust proxy.rs 进程 env 注入,覆盖客户端联网与之后 spawn 的 CLI 子进程
- 拔出插件 = 浮层断电(入口事件无人订阅),数值保留,重启后 env 不再注入
- 入口:侧栏齿轮菜单 / 底栏钉住按钮,经事件总线唤起,壳与插件互不引用
