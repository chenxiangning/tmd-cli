# 工作台聚焦页设计:三视图三撤一合(项目列表/时间线/待跟进 → 聚焦)

- 日期:2026-10-12
- 状态:已实施(门禁全绿;1421 桩目检有事态/清净态双态通过)。v1.1 布局重构同日落地(见文末修订)
- 需求来源:大仙——三视图业务数据「不知道解决什么问题」;调研 `docs/research/workbench-three-views-redesign.md` 判无效设计成立,方案 A(三撤一合)经 `docs/design/workbench-focus-view.html` v2 双屏原型定稿

## 背景与目标

项目列表/时间线/待跟进三页签是 projectHub(PM 报表工具)移植遗产,与「单人 + AI 会话」场景双重错位(数据错位 + 场景错位;调研文档有 16 项目/13 空壳/6 任务/2 DDL 的量化证据)。目标:撤三页签、合一个「聚焦」页签,消费自动可得的活动流数据,让手工字段退为详情页属性;页签 7 → 5(概览 / 聚焦 / 任务看板 / 文档 / 工作日志)。

## 方案取舍

### 页签结构

**选定:三撤一合**——删 list/timeline/followups 三页签,新增 focus「聚焦」;项目索引不由概览底部承担,收进聚焦页第三段(空壳折叠索引)。调研方案 A 的「概览底部加索引 or 聚焦页承担,二选一随实现定」在此定为聚焦页承担:概览保持全量健康结论页定位,不混入索引交互。

- 否决 逐个改造(方案 B):收敛不彻底,行动入口仍分散。
- 否决 仅删时间线(方案 C):不回应「三类都无效」的判断。

### 聚焦页三段(自上而下 = 行动 → 展望 → 状态)

1. **要处理**:`followUpBuckets` 复用,只展开 已逾期/今天到期/本周内 三桶并排(红橙蓝紧迫梯度);**更晚与未排期折叠为一行**,展开才见。行内操作沿用待跟进(勾完成 / 推进 / 删除带确认),补两条:项目名 chip 直达项目详情;**「会话 ×n」徽标**在任务有关联会话时出现,点击经 `openLink` 直跳(收覆盖层语义在 openLink 内已含 `sessionViewRequested`)。
2. **接下来 14 天**:14 格固定刻度水平带,每格只放 **项目 DDL chip(风险三色)+ 当日到期任务数徽标(悬停 title 见明细)**;空日零占位。v1「带里堆任务卡」被否决——与要处理/任务看板构成第三处任务数据重复;日级细节由工作日志月视图日格承担,两级各管各的粒度。
3. **项目脉搏**:只列有任务/有活动/有 DDL 的「被跟踪」项目,紧凑行 = 项目名(名下半宽 2px 手工进度微条,数值收 tooltip)+ 风险徽标 + 截止日 + 未完任务数 + **最近活动**(会话/文档/进展三源取最新,相对日文案)+ 详情/开会话两钮。空壳项目(无任务/活动/日期)默认折叠一行「N 个未跟踪项目」,展开为**带过滤框的字母序索引**(吸收原项目列表的找项目场景)。

### 结论行分工

聚焦页顶部是**行动一句话**(X 条逾期 / X 条今天到期 / 清净口径),概览 headline 保持全局健康口径,两处不重复措辞。

### 清净态(空态一等公民)

真实数据常态是稀疏,「要处理」空段不渲染三列空卡片:给「今天清净」结论 + 一句话 + 两钮(去任务看板 / 新建任务——后者经 `boardFormOpen` 信号让看板直接展开新建表单,同 docsFilter 先例);14 天带稀疏照摆。

### 概览同步收敛

模块负载图与负责人负载图同建在死轴上(模块 16/16「其他项目」、负责人 16/16「我」),随本方案一并**下线**:`insights.ts` 删 `moduleWorkload/ownerWorkload`,`charts.tsx` 删 `ModuleLoadBars/OwnerRankBars`,概览收敛为 结论 + KPI + 风险分布 + 进度分布 + 马上处理 + 本周到期。

## v1.1 布局重构(同日,大仙首版目检反馈「有点乱、布局不清晰」)

首版三处布局病灶(截图实证):三桶并排网格在空桶处留「—」占位,视觉断裂;14 天带 14 格固定刻度,13 个空格子淹没 1 个有事格;脉搏行 flex 布局列不对位。修订(数据与交互零变化,纯表达层):

1. **要处理改单流分组列表**:三桶并排网格 → 垂直分组流,空桶整组不渲染(含「—」占位),组头(红/橙/蓝 + 计数)只在有行时出现;行几何与「更晚」展开行完全一致。
2. **14 天带只有事日渲染**:空日不占位,有事日渲染为紧凑 chip(「今天 — 任务 ×1」「10/13 二 [内容分析]」),横向 flex-wrap;全空落一行「未来 14 天没有到期事项。」;周末底纹与固定 14 格刻度一并删除(空格占位正是首版「乱」的主源)。
3. **脉搏行 grid 定列**:`grid-template-columns: 150px auto auto auto minmax(0,1fr) auto`,六列(名/风险/截止/未完/活动/操作)逐行对位;项目名下划线链接改纯文本态 hover 变色;≤860px 容器回落 flex 换行(活动行 order 5 独占一行)。
4. **空壳索引过滤框并入折叠条**:展开态过滤框与「N 个未跟踪项目」同行,chip 墙直接铺,删「项目索引(字母序)」多余说明行。

取舍:否决「三桶保持并排 + 空桶消隐」——单流分组让扫描方向唯一(自上而下),并排三列天然引入横向扫描且列宽挤压行内动作;14 天带保留固定刻度的价值只在「看空白密度」,实测 16 项目仅 2 DDL 的真实数据下空格噪声远大于信息。
