# 客户端整体细节打磨(A+B)设计

日期:2026-11-03
状态:已落地并完成代码评审(2026-11-03;真实窗口逐项交互待用户验收)

## 背景与目标

当前客户端有 48 个注册插件,主功能链完整,但细节层仍存在两类问题:

1. 可见行为与真实异步行为不一致:取消后后台仍执行、旧计时器关闭新弹窗、连续贴图覆盖、保存回调污染下一份配置。
2. 触达面的反馈与交互标准不齐:脏稿取消确认不一致、busy 可关闭、旧地址可复制、错误缺少语义、窄窗口固定宽度溢出、部分菜单缺 Esc。

目标是以小步、可回归的方式完成 A(状态与异步缺陷)+ B(触达面视觉与交互一致性),不改信息架构、不引入全局新框架、不扩大新功能面、不修改版本号。

## 方案取舍

| 主题 | 选定 | 否决 |
| --- | --- | --- |
| 实施范围 | 六组已实证缺陷及其直接触达面的 UI/交互打磨 | 全应用换皮;一次扫完所有历史体验债 |
| 异步治理 | 各模块使用现有 alive/ref/effect cleanup 范式,按操作边界收口 | 新建全局任务框架或请求库 |
| 弹层 | 保留 Relay/Retry 当前结构与视觉,补 busy 关闭闸、窄屏和反馈语义 | 本批重写 DialogShell 或迁移全部弹窗 |
| 提示 | 复用各面板既有错误区、状态文案与局部轻提示 | 新建全局 toast 体系;用原生 alert |
| 配置保存 | 单飞写盘,卸载后停止 UI/父态回调;正在执行的磁盘写不伪称取消 | 引入可假取消的 IPC;重写配置格式层 |
| 文件定位失败 | 记录为后续候选,不混入本批 | 为本批五个调用点临时发明五种提示样式 |

## 设计

### A1. 工作日志便签:弃稿与贴图一致性

- 「取消」按钮与 Esc 共用同一入口:无修改直接退出;有未保存文本或图片时先弹既有 ConfirmDialog。
- 贴图完成时基于最新 images 合并,不使用发起粘贴时的旧数组,避免连续贴图互相覆盖。
- 每次编辑会话使用代次/存活闸;取消、保存完成或卸载后,迟到贴图结果不得重新 setState、上报 dirty 或写草稿镜像。
- 图片文件已经落盘但界面已取消时不反向删除资产,避免误伤;只保证不再污染当前编辑态。

### A2+B1. MCP 安装弹窗:延迟关闭与反馈

- 安装成功后的 1.5 秒关闭放入带 cleanup 的 effect,与同模块 ServerEditModal 对齐。
- 用户提前关闭或组件卸载时清计时器,旧弹窗不得关闭随后打开的新弹窗。
- 保存期间维持现有 locked;保存成功态不重复提交。

### A3+B2. CLI 配置:保存单飞与状态隔离

- ConfigFile 以同步 ref 闸保证 persist 单飞;GUI、raw 与 ⌘S 共享同一写盘入口。
- 卸载后旧 persist 不再 setState,也不再调用 onDirtyChange 清除或覆盖下一份配置的脏态。
- GUI 保存成功后以写盘产物的规范化值同步表单并清脏,禁止再用保存前的旧 baseline closure 把已保存表单重新标脏;回归测试覆盖保存后 savebar 消失。
- 保存成功的局部 toast 使用可清理、可复位计时器;失败仍保留持久错误条,不用短 toast 掩盖。
- 错误区长路径与长错误文本允许换行,保存区在窄宽度下不挤压、不横向溢出。

### A4+B3. Relay/Retry:busy 关闭闸与弹层适配

- 两弹层各自提供 closeGuarded:创建会话、挂摘要或回填进行中,Esc、取消按钮与遮罩关闭均忽略。
- busy 时取消按钮 disabled,主按钮保留明确进行中文案;非 busy 行为不变。
- 固定 460px 卡片补视口最大宽度与最大高度;内容可纵向滚动,底部动作区允许换行,窄窗口不横向溢出。
- 异步错误使用 role=alert;弹层忙态用 aria-busy 表达,不改变既有焦点圈闭。

### A5+B4. Web 访问设置:状态与复制反馈

- webAccessStatus 刷新失败时清空旧 info,错误期间不再展示或复制可能失效的旧地址。
- copyText reject 进入现有错误区,不伪报已复制;成功才显示「已复制」。
- copied 复位计时器可清理、可复位,连续复制以最后一次为准。
- 复制图标补 aria-label;错误 role=alert,复制成功反馈 role=status。

### A6+B5. 侧栏文件菜单:键盘与形制

- WsfbMoreMenu 接现有 useEscClose,Esc 只关闭栈顶菜单。
- 打开后聚焦首个菜单项,按钮补 role=menuitem;Tab 保持原生顺序,遮罩与右键关闭行为不变。
- 不调整文件树布局、图标、颜色或行高。

### 实施顺序与回归纪律

1. 先修 A1-A6 及各自最小测试,再做 B1-B5 的触达面打磨。
2. 每批修改后跑相关模块测试与 typecheck;不单独重跑局部命令代替最终全链。
3. 完成后进行独立 code review,重点检查异步代次、卸载清理、关闭闸与词典完整性。
4. 保留当前 0.4.8 全部未提交改动;不修改版本文件,不在本设计中授权提交。

## 验证

- 便签:脏稿点取消必须确认;连续两张乱序完成的贴图都保留;取消后迟到结果零回写。
- MCP:fake timers 验证提前关闭后旧计时器不再触发第二次 onClose。
- 配置:重复保存只有一次写盘;旧实例完成后不碰新实例 dirty;toast 卸载无迟到回调。
- Relay/Retry:busy 下 Esc、取消、遮罩均不关闭;完成后可正常关闭;窄视口无固定宽度溢出。
- Web 访问:刷新失败清旧地址;复制失败有错误;连续复制不会被旧计时器提前复位。
- 文件菜单:Esc、初始焦点、menuitem 语义与既有鼠标路径正常。
- 全量执行 `pnpm check:gate`、Rust `cargo test && cargo clippy --all-targets -- -D warnings && cargo fmt --check`、`npx react-doctor@latest -y` 100、`git diff --check`。
- 使用 `pnpm tauri:dev` 对触达面做真实窗口目检,覆盖正常宽度、窄窗口、深浅主题和 busy/错误态;未实际点击的项目不得写成已验收。
