## 二轮深扫修正记录(首轮错误,以本轮为准)

1. **编辑器查找/替换已存在,撤项**:首轮只扫了 `src/plugins/files/editor/` 漏掉 `src/kernel/cmEditor/`——`FileCodeEditorImpl.tsx:26-56` 显式接 `@codemirror/search`(search({top:true}) + Mod-f keymap),files/ssh/cli-config 三方共用同一壳(FileCodeEditor lazy)。教训:扫描面必须覆盖 kernel 层。
2. **重启恢复不走冻结快照**:首轮示例页误写「快照先上屏」。实证:重启后内存 outputBuffers/screenMirror 全丢,`terminalFreeze.ts:9-10` 明示侧栏重开磁盘会话存档天然不命中;恢复走 `openDiskSession → sessionSpawn.open()` 自带 prefetchDiskTail 磁盘先行回放。且持久对象必须是三段身份(sessionOverlayKey),不能是 tmd PTY id(sessionTabs.ts:27,头注 :15)。
3. **记忆文件路径仓库零知识**:全库无硬编码 CLAUDE.md/AGENTS.md 绝对路径,只有 academy 文案与 codex sessionHead 包装识别;面板必须声明式(profile 增声明字段,骨架照 skillSources.ts 缺失隐藏不猜测),gemini/dsh/grok/omp 路径显「— 未声明」。
4. **⌘Q 腿要 Rust**:前端 `onCloseRequested` 只覆盖窗口关闭;应用级退出需 Rust app_setup.rs 加 ExitRequested prevent + 事件桥(现仅处理 Focused),页面如实标注。
5. **静音 key 必须三段身份**:裸 tmd sessionId 跨 resume 断链(anchorJump.ts:123);quota 腿静音绝不写 quotaSeen(跨周期永久抑制),拦截点在 fireQuota 的 record 之后 sendOsNotification 之前。
