# 0.4.5 长期任务批次规划(功能增强 + 换角度体检)

> 日期:2026-10-25 · 状态:已收口(十项全交付,收口评审见 `docs/review/2026-10-25-045-batch-review.md`)
> 决定:10 项候选全量实施,分四批推进,过程 AI 自决不打断,最终交变更清单/影响范围/UI 感知点验收。

## 背景与目标

0.4.4 发版收口后,从三类底料交叉归纳出 10 项下版本工作:0.4.3/0.4.4 评审 record-only 欠账、FEATURES 能力缺口、代码实测核查(终端搜索/改键面等已有项已排除)。目标 = bug 欠账清零 + 已有能力做深一层 + 用「不读代码跑真实场景」的新角度收边角。

## 批次划分

- **批次 A(bug 欠账,有据可查)**
  1. 轮次闸三面统一:mobile StatusBar 模型 chip 无闸、⌘K 抽屉 /model 零拦截、输入框直敲 /model——ask 等待期写入会被 CLI 当答案提交,统一收口(桌面 chip 闸 0.4.4 已做)。
  2. checkpoints 回落沿对称化:关窗/重绑沿 byKey LRU 摘除、重绑未首拉闪一拍、回落读刷 recency、staleSessionId 推导抽纯函数补测试。
  3. read_file 二进制头部 sniff:Rust 读前头部判定,不再整读 100MB 才拒。
- **批次 B(深度增强)**
  4. 终端搜索扩展到磁盘日志:SearchAddon 只搜滚动缓冲,溢出缓冲自动查 64MB 旋转日志全文并跳读页定位。
  5. Git blame 视图:git2 blame,文件面板行级归因,与 commit diff 串链。
  6. Git stash 管理面:列表/pop/apply/drop,现状 stash 仅 pull rebase 兜底内部使用。
- **批次 C(呈现统一与对齐)**
  7. 错误呈现层统一:Rust 错误码化 + 分类文案,消 en/ja 下中外混排(anim read-failed 为代表)。
  8. mobile 深度对齐批:评审记档 MobileEngine 无 midTurn 概念等差距,按使用频率择项收编。
- **批次 D(换角度体检)**
  9. 挂机浸泡审计:增长面静态审计(监听/定时器/LRU 注册-清理配平)+ 桩实测内存采样。
  10. 满额态规模化实测:500+ 会话/200 归档满/10 tab/5 万文件仓/8M 编辑闸边缘压测,收边角。

## 方案取舍

- 选定:全量 10 项分四批、每项独立提交;批次 D 产出边角当轮修进同版本。
- 被否决:一次性大提交(评审粒度差、回退难);先发 0.4.5 再发 0.5.0 两轮(用户要求一批收口)。

- Rust:cargo test / clippy -D warnings / fmt --check。
- UI 行为:1421 桩目检(若 dev server 在跑)。
