## M0 交付(当日完成)

范围 = 调研文档第六节的 M0 闭环验证:场景 JSON v1 契约 + Canvas 2D 纯函数渲染器 + 播放器 + 示例项目。

- 数据模型(`src/core/`): types / timeline(场景拼接与缓动)/ highlight(高亮短语切分)/ wrap(贪心折行)/ normalize(宽容归一化,agent 半成品也能播)。
- 渲染器(`src/core/render/`): `drawFrame(ctx, project, t)` 纯函数,10 种元素(标题芯片/正文/输入框/代码块/表格/便签/徽章/色块数组/连线/图片)x 5 种入场动画;预览与将来导出唯一路径。
- 播放器(`src/app/`): rAF 循环播放、进度擦洗、场景跳转、键盘(空格/左右键)、拖拽与文件打开 JSON、错误中文提示。
- 示例项目 `src/samples/bpe.json`: 四场景 BPE 分词演示,同时是 schema 活例。
- 桌面壳 `src-tauri/`: Tauri 2 最小壳 + 零依赖脚本生成的全套图标(`pnpm tauri icon` 派生 icns/ico)。
- 契约文档 `docs/schema.md`: agent 协议权威文档;新仓自带精简 `AGENTS.md`(沿用 300 行铁则/中文半角/提交格式)。

## 用户实测反馈轮(同日第四批,四个问题全修复)

1. **底部无法折叠**:根因是场景条与时间线是两个独立面板,折叠只藏了时间线。重构为统一「动画操作台」:TransportBar(上一场景/播放暂停/下一场景/全局时间/缩放/适应)+ SceneStrip(场景芯片与管理 + 停留秒数)+ 轨道区,三段一个折叠钮整体收放;旧 SceneBar 删除。
2. **连线不能调角度、无曲线**:连线选中后画布显示「端点圆点 ×2 + 琥珀曲线控制点」,端点拖拽改角度,控制点拖拽改弯曲度(新增 `curve` 字段,二次贝塞尔渲染,箭头沿切线,标签挂在 t=0.5,命中按曲线采样);纯逻辑抽到 stageOverlay.ts。
3. **缺基础形状**:新增 `shape` 元素(矩形/圆形/三角形),填充/描边/描边宽/圆角独立可控;元素库新增「形状」分组(带变体创建,拖拽数据格式扩为 `kind:variant`)。
4. 顺带修复:连线新元素落点错误(端点未随落点平移,落在画布左上角外)。
- 验证:check 全链绿 54 测(贝塞尔命中/shape 归一化/新类型);浏览器实开目检通过(操作台三段/整体折叠持久化/三角形渲染/曲线拖拽)。已知自动化环境怪癖(非产品问题):IAB 合成点击在静态页面上 actionability 偶发挂死,目检改走 evaluate 派发 click + cua 坐标。
