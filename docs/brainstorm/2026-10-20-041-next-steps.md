- 日期:2026-10-20
- 状态:规划梳理(候选菜单已按实测盘点,待大仙裁选批次与范围)
- 上游:`docs/brainstorm/2026-10-19-042-followup.md`(0.4.0 追加批)、`docs/review/2026-10-19-040-release-review2.md`(发版二轮)、`docs/review/2026-10-20-24h-commit-review.md`(发版后窗口)、`openspec/changes/2026-09-22-mobile-app-m2-light-interaction/tasks.md`(M2 真机余项)
- 版本口径:0.4.0 已发(tag `v0.4.0`,2026-10-20),0.4.1 为下一版;若大仙要跳 0.5.0,拍板时改号即可,本文字段不变

## 结论

**0.4.1 不接新能力面,定位「稳态收口版」——把 0.4.0 的高速产出固化成可长期运转的基线。** 三条理由:

1. **0.4.0 是超重版本**:八项向内治理 + 042 混合批五项 + 连续性六项 + footprint 新插件,同一版内落了 4 个批次、57 笔提交(Tmd-0.4.0 领先 main 57 笔),单版新增面超过 0.3.x 任何一版。密集产出必然带毛边,现在缺的不是功能。
2. **真机债已跨五个版本累积到 28 项**,0.4.0 CHANGELOG 里「真机验收债陪跑」条目至今未勾(042-mixed tasks.md:59)。桩目检全绿 ≠ 真机可用,这是当前最大的质量敞口。
3. **两处硬账未清**:main 未合流(0.4.0 只在分支上)、openspec 三个已落地 change 未归档。账实不对齐会让下一版的范围判断失真。

批次建议:P0 合流对账(1 天) → P0 真机债清零(1-2 天,需大仙在场) → P1 性能与稳定性(2-3 天) → P1 一致性打磨(2-3 天)。**总量 6-9 个工作日,零新能力面。**

## 六、单项条目写法示例(样板,后续每项照此写)

以下两条是给实施会话用的**写法示范**,不是额外范围——照这个粒度写,评审才能逐条核。

### 示例 A(性能类):轮询面收编

```
项:轮询面收编(3.1)
现状:全仓 59 处 setInterval,分布 20+ 文件。已带活性门控的仅 6 处(checkpoints 三处 /
      ssh 面板 / 看板 / 足迹),其余为裸周期;失焦后无统一暂停语义。证据:grep setInterval。
改法:①先产审计表(文件 / 周期 / 触发条件 / 门控 / 失焦行为),放进 docs/review/;
      ②新增 kernel pollClock 原语(单一 tick 源 + 订阅者声明最小周期 + 失焦/隐藏暂停),
      只迁移「无门控 + 周期 ≤5s」的项,一次性迁移面控制在 10 处以内;
      ③剩余项登记豁免理由(如 quota 轮询必须跨失焦跑)。
不做:不重写既有已门控项;不引入新状态库;不把 tick 源做成全局单例以外的形态。
验收:审计表覆盖 59/59;迁移项失焦 5 分钟 CPU <1%;既有 6 处门控项行为零变化(测试钉住)。
成本:M(0.5-1 天)。风险:quota / 状态巡航两类必须跨失焦,误收会掉功能——审计表先标红。
```

### 示例 B(结构类):299 行拆解

```
项:行数天花板拆解(4.1)
现状:62 个文件 ≥295 行,25 个正好 299 行。它们不是"刚好简洁",是每次长到 300 就被迫
      手工压缩过一次,下一笔改动仍要先拆。证据:python 行数扫描(2026-10-20)。
改法:①按「下一次可能要改」排序取前 8 个(workspace/index.tsx、session-viewer/liveOverlay.tsx、
      session-board/BoardTab.tsx、mcp-hub/ServerEditModal.tsx、workbench journal 三件);
      ②每个只做一件事:把渲染分支/子组件搬到同目录新文件,零语义改动;
      ③每拆一个跑一次 check:gate,不批量攒。
不做:不为凑行数改结构(不合并模块、不抽过度抽象);不碰 file-size-exempt 的 9 个文件。
验收:299 行文件 = 0;前 8 个文件 ≤250;拆分前后测试用例数不减;每笔提交单独 gate 绿。
成本:S-M(每文件 0.5-1h)。风险:搬迁引出循环依赖——按架构边界脚本每笔验,红了立即回退。
```

## 七、不做清单(防范围漂移)

- **不接新能力面**:mobile M3(深度后台/APNs)、intent-canvas 精化、看板拖拽键盘替代、插件市场远程源。
- **不动外部依赖项**:signing-pipeline 继续卡 APPLE_* secrets,不排期。
- **不做重写型重构**:轮询收编只收无门控项,299 拆解只搬不改;任何「顺手重构」一律拒。
- **不新增设置键**:本版所有条目零新设置项(除 ⌘Q 闸复用既有退出确认)。
- **不再开候选示例组**:本版无新特性,不做 `docs/design/043-candidates/`。

## 八、验收标准(可测,缺一即未就绪)

1. `main == Tmd-0.4.0` 拓扑一致;`git status` 净。
2. `openspec/changes/` 未归档 ≤2(M2 真机在途 / signing 卡 secrets),且两个都有卡点说明。
