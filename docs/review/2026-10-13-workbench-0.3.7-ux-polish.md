## A. 真实数据暴露的使用逻辑问题

1. **一键关联工作区 = 无预选全量导入**(✓ WorkbenchTab.tsx:66-75, views.ts:80-83)。`linkableWorkspaces` 只排 default,工作区列表里的 `.ssh`/`home`/`Downloads` 一律建项目,点击前无清单确认、无排除规则(隐藏目录/家目录/非代码目录),事中无进度、部分失败静默(`.catch(() => undefined)`,全组 reject 才进横幅)。现场后果:16 项目 14 空壳,污染一切全量统计。方向:一键关联改「候选清单勾选」弹层(默认不勾隐藏目录),或至少排除点开头目录;部分失败补 toast 计数。
2. **概览与聚焦的空壳口径不一致**。聚焦页脉搏已把空壳折进「13 个未跟踪项目」,但概览 focusLine「16 个项目整体在跑」、KPI 项目总数 16、平均进度 6%、风险环「未排期 14」、进度分布 0% 桶 14 根,全部被空壳统治——用户看到的概览是对着噪声做判断。方向:概览侧复用 focusModel 的被跟踪判定(有未完成任务|有 DDL|近 7 天有活动),空壳并入「未跟踪 N 个」一行;`focusLine` 同步改成按被跟踪集计账。
3. **聚焦页「接下来 14 天」chip 语义混装**(桩目检实证)。「今天 — [内容分析] 任务×2」:项目名取自当日 DDL 项目,任务计数却是全工作台当日到期任务(实际属于 tmd-cli),且 10/15 的 tmd-cli chip 无计数徽标——同排 chip 有数没数不一致,跨项目归因会误导。方向:chip 拆双行或「DDL:内容分析 · 任务×2(tmd-cli)」显式归属;计数徽标有无统一。
4. **脉搏行活动摘要密语**(桩目检实证)。springboot-demo 行「会话·2天前·1+1+3」无解释,`1+1+3` 只能猜;对照 ACTIVITY_LABELS(FocusScreen.tsx:22)已有中文标签,数字段缺语义。方向:改「会话 5(新建 1/续起 1/完结 3)」或 title 补全。
5. **月视图工具栏统计与格子现实矛盾**(桩目检实证,待真机复核):工具栏「本月 0 天有记录 · 0 会话 · 0 篇文章」与格子成排「已生成」chip 同屏并存;article 事实在场而统计为 0,说明 monthStats(JournalTab.tsx:93-95)口径与渲染源不同源。方向:统计与格子共用 journalStore 同一快照派生,禁止两套扫描。
6. **看板 total 与列头计数对不上**(✓ TaskBoard.tsx:79 vs 155-166)。「全部任务 8」含 cancelled,四列头只算 BOARD_STATUSES,cancelled 任务全工作台无处可见。方向:cancelled 从 total 剔除,或列头旁补「已取消 N」折叠段。
7. **done 列空态与「+N 更早」同列并存**(✓ TaskBoard.tsx:225-229)。visible 0 显示「拖到此列」同时 hiddenCount>0 显示「+N 更早」,自相矛盾。方向:有隐藏任务时隐藏空态占位。

## B. 布局与响应式(截图实证)

1. **看板泳道窄容器裁切 = 本轮最重**。泳道 grid `minmax(150px,220px) + 4×minmax(190px,1fr)` 最小约 910px(workbench.css wb-lane-grid),工作台中栏在 1600×1000(右侧文件面板开)约 520px、1920×1200 同面板开约 700px,tmd-cli 泳道只见待办/进行中,springboot-demo 的 3 个已完成任务一张卡不可见;每条泳道独立横向滚动且无渐隐/滚动提示,用户无从知道右边还有列。聚焦页已有 `@container` 降级(workbench-focus.css:76-89),看板没有。方向:泳道套 `@container` 查询,窄容器改「泳道内横向滚动 + 右缘渐隐 + 列头吸顶」或列最小宽降到 150px;至少给 overflow 区加可视滚动条。
2. **docgen 阅读列过窄 + 底部动作卡盖正文**(桩目检实证,docs 页签 520px 中栏):正文实测约 11 字/行;ReaderFoot 六按钮悬浮卡直接叠在正文上,无 scroll padding 让出末行。方向:窄容器下 ReaderFoot 改文档流内落底(非悬浮),阅读列给 `max-width` 居中而非占满;`dg-reader-title` 长标题加截断(ReaderChrome.tsx:24)。〔复核 2026-10-13:限宽被用户否决——docgen `.dg-reader-body` 72ch 与 journal `.dj-art-page` 860px 均撤,还原占满自适应;仅保留 Foot 落底与标题截断。〕
3. **月视图空日占位噪音**:15-31 每个空格重复「无会话 · …」灰字 ×17、「休·国庆…」节假日 chip ×9,日历形状被灰字淹没。方向:空日占位只在 hover/今天前后 3 天出现,节假日图例收进工具栏 pill。
4. **DocGenCenter 排程卡与列表行标题无截断**(DocGenCenter.tsx:175-180):长模板名撑破窄列表列。

## C. 交互一致性 / 危险操作(抽查 ✓ 两条)

1. **任务卡片芯片「取消=丢弃」**(✓ TaskCardChip.tsx:36-39):编辑弹层 `onCancel` 里 `dropPendingTaskCard`,用户点开芯片编辑又点取消,任务上下文整卡消失且无挽回;对照同弹层「✕」才是丢弃入口。方向:取消只关窗,丢弃留给 ✕(丢弃可加撤销 toast)。
2. **命名弹窗 IME 回车**(✓ TaskDetailView.tsx:274-278):`onKeyDown` 未查 `isComposing`,中文选词回车直接创建关联会话;同仓 TaskFormView:94 / drawerTabs:156 / NoteEditor:170 都已防。一行修复。
3. **确认强度倒挂**(journal/TaskPanel.tsx:58-71):终止运行中的生成会话(杀真实 CLI 会话)单击即执行,删一条历史记录反而两击;失败任务「重试」绕过全域「两击确认」约定(MonthView/ArticleTab 都守)。方向:破坏度对齐——杀会话补确认或撤销窗,重试并入两击口径。
4. **docgen 终止无确认**(DocGenReader.tsx:129-131):run 态终止立即收割会话,与 DrawerDocsTab 删文档有 WbConfirm 的口径不一;docState 流转单击即循环生效无撤销(ReaderChrome.tsx:83)。
5. **丢稿路径残余**:TaskDetailView 描述 dirty 点「返回」静默丢稿;ProjectFormModal 已填字段时 Esc/点背板静默关窗(H2 只保了提交失败留窗)。NoteEditor 有脏稿确认先例,journalTabs 放行闸文案未指明是哪一天的草稿(用户从月视图连点多格时弹窗来源不明)。
6. **in-flight 缺失族**:一键关联在途可重复点击按同一份旧快照重复建项目(WorkbenchTab.tsx:66-75,无禁用);附件上传 24MB base64 期间按钮无态(ui.tsx:112-125);ScheduleCard toggle 无 pending 可乱序连点(DocGenCenter.tsx:139-146);关联会话 select 在途不禁用(TaskDetailView.tsx:177-188);NoteEditor 保存无 saving 态可连按。
7. **docgen 换引擎只给「下一个」**(ReaderChrome.tsx:76-78):`(idx+1)%len` 轮转,想换到指定引擎要点多次。
8. **对比视图上一版失败与「不可解析」共用文案**(DocGenReader.tsx:47):文件丢失 vs 格式问题不可辨,且无当前版那样的重试入口。
9. **docgen 转任务防重靠标题前 80 字启发式**(DocGenReader.tsx:54-61):用户改过任务标题按钮回亮可重复转;快照刷新窗口内双击可重复。

## F. 数据层 / 状态逻辑

1. **addUpdate/deleteUpdate 假成功**(✓ store.ts:229-243):不校验目标存在,map 空转照常写盘;同文件 updateProject/updateTask 都显式 throw。项目被删/AI 回写竞态后「进展已记录」是假的。方向:补未命中 throw,与同族契约对齐。
2. **4s 轮询整载清错误条**(store.ts:69):用户正看「落盘失败」横幅,任何一次外部指纹变化触发 reload 即无声抹掉错误,即便无人写入。方向:reload 失败保留 error、成功仅在新错误发生时清。
3. **hydrateProject 静默丢非法 id 项目**(store.ts:31-32):形状不符条目每次装载被过滤,UI 无任何提示,用户视角「数据丢了」。方向:进 error 横幅计数(「N 条损坏记录已忽略」)或隔离区可见。
4. **项目详情深链冷启动假「不存在」**(桩目检实证):store 未装载时打开 `wb.project` tab 直接渲染「项目不存在或已删除」;装载后 refresh 重开同 tab 也不恢复(ProjectTab.tsx:36-43 仅 focusTab 变化才重挂,上轮 R6 收紧后 payload 其余变化不触发)。方向:ProjectDetail 对 `!loaded` 渲染装载态,loaded 后按当前 payload 重解析;或 openProjectTab 深链先 `ensureWorkbenchLoaded`。
5. **渲染期纯函数无 memo**(focusModel.ts:76/97-110、insights.ts:38-55):一次聚焦页渲染 followUpBuckets 全量跑 3+ 遍、kpis/风险/进度各自 reduce 全表;16 项目无感,任务/项目上量后聚焦页与概览会成更新风暴热点。方向:入口处 useMemo(projects,today),或纯函数层做按引用缓存。
6. **DiffView key 撞车**(DocGenBlocks.tsx:160):`${sign}:${text}` 同符号同文本两行撞 key,风险条目重复常见。
7. **行动项勾选纯本地态**(DocGenBlocks.tsx:30-36):切版本/重进全丢且不回写,阅读态打勾易被当成已保存——至少加「未保存」暗示或回写 md。
8. **docgen 排程 time 空串可落盘**(DocGenDialog.tsx:209-214):清空时间勾选排程直接提交,ScheduleCard 显示空时间;提交前缺校验。
9. **focusBand 固定 +24h 跨 DST**(focusModel.ts:66-69):国内无感,留注释即可。
