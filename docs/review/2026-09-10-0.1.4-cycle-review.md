## 结论

**不可合并。** 本地插件系统两个缺陷必须先修:

1. **BLOCKER —— 信任闸双读断裂,被执行的字节从未经过哈希校验。** `plugin_scan` 在 `stamp()`(src-tauri/src/plugins.rs:100)算出的 sha256 是信任判据;但 `ensureLoaded`(src/kernel/localPlugins.ts:88)另发 `plugin_read_file` 读当时字节直接 `importBundle`(:95),全程不重哈希。「确认/装载时读到的字节 == 用户批准的字节」不成立:按本特性自述威胁模型(「AI 有 shell」,hash.rs 注释),对手监听信任落盘后换掉入口文件,同一次确认流内毫秒后的读即拿到恶意内容并以信任身份执行;boot 自动装载流(scan→读两次 IPC)同病。**修法:Rust 加原子「读+哈希」命令(单次 fs::read 返回 {content, sha256}),前端只信该哈希再 import;或前端对读回文本重算 SHA-256 与信任值比对。** 注意:spec 2026-09-10-local-plugins-design.md:74 的「scan 给哈希 + 前端再读 bundle」链路本身即此设计,洞是设计期带入的,修 spec 一并改。
2. **MAJOR —— activate 失败仍被无条件落「已激活」戳,插件重启前永久卡死。** `wrapSafePlugin` 吞错(localPluginLoad.ts:124-131,白屏保护,设计如此),被包装 activate 永不 reject;而 `doRescan`:232 与 `confirmLocalPlugin`:269 在 `await host.activateLate(...)` 后无条件 `rec.activatedHash = rec.contentHash`,与 localPlugins.ts:116 自己的设计注释(「activate 真跑成功才落戳」)直接矛盾。后果链:① 失败插件同时带 activatedHash + activateError;② 重扫在 :226 `if (rec.activatedHash) continue` 永久跳过,AI 修复文件也不再重试;③ 用户点「确认更新」在 confirmLocalPlugin:258 提前 return 成 no-op;④ lifecycle 占位已落(pluginLifecycle.ts:102),`isPluginActive=true` 假激活,重试撞「插件已激活」throw 并把真实错误覆盖成误导文案;⑤ boot 失败(无戳)插件走另一极端:每次 turnSettled 都重试且第二次起错误被「插件已激活」覆盖。**修法:删 :232/:269 两行显式落戳,统一交 wrapper onSuccess(boot 路径已如此);onSuccess 顺手清 activateError;scanToRecord 在 contentHash 变化时丢弃旧 activateError;测试补一条「wrapper 吞错路径不落戳」用例(现有测试 mock 掉 activateLate,全部绕过该路径)。**

其余:15 minor / 17 nit,明细如下。验证面全绿;架构铁律零违规;checkpoints 防误删成立。

## 专项结论

- **checkpoints 防误删(本变更存在意义):成立。** 封口(events.rs:235-236 强制 existed_before + before_oid 留空)、视图(view.rs 双分支 no_baseline)、回退(restore.rs:131-135 硬闸位于失配与手术擦除之前)三层一致;次轮前像链永远够不到用户原始内容;三处前端回退入口均 `!noBaseline` 摘除。事件 ts 走 CLI 自记时间戳不赌 mtime,ext4 coarse 时钟陷阱不适用。
- **兼容性**:settings 新字段默认值 + sanitize 合格(旧 settings.json 直读);no_baseline 视图期现算零迁移;旧前端忽略新字段、新前端配旧后端无组合风险;版本号三处(package.json/Cargo.toml/tauri.conf.json)0.1.4 一致。
- **性能**:除 M9(双拷贝)/M15(存在性整读)外无热点问题;DOM 渲染器性能回退风险有 ponytail 注释备案(可视行绘制,复评条件写明);WebGL 依赖移除彻底(package.json/lock/源码零残留,仅决策注释)。
- **死代码**:见 nit 表(bootOn / skip_dirs / pluginReadVersion / pluginSdk re-exports / __TMD_SHIMS 重复 / editWatch 不可达分支);WebGL 无残留;无 shim/别名/废弃路径遗留。
