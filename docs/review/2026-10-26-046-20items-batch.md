   本轮交付门禁测试(注入假键验红/还原验绿,防假绿),不重补词典。
2. **弱网双数据面不动**:pollTranscript 已走 fs_read_tail_changed 尺寸闸(unchanged 零读零传)+
   poke 300ms 边沿,「2s 拉 256KB」主张不成立。只修 replay 闸卡死(真实缺陷:无 try/finally,
   一次 reject 即 replaying 永真)。
3. **oneshot 三家不接**:kimi/grok 的 -p/--single 必填串参数(数百 KB prompt 爆 argv,无 stdin 通道,
   --help 管道实证)、dsh 为 profile 启动器(无 print 模式)——回落 TUI 是实证后的正确形态,
   genSession 注释钉住防后人凭印象补。
4. **WSL 字节预览维持 M1**:ByteChannelView 四子组件各自读本地 bytes,远程化 = 四条数据层改造,
   与写回闭环不成比例;守卫文案如实(「暂不支持」)。
5. **错误 E_ 扩域推迟**:133 处统一出口后,无分类消费需求前给 wsl 域加码是投机(YAGNI);
   ErrorBanner 已就位,域映射按需扩。
6. **搜索正则未做**:Cargo.toml 无 regex 依赖、std 无正则,零依赖原则下只做 glob;
   替换闭环(逐文件写回确认 UI)另轮。

## 三、教训

1. **并行 agent 与主会话共享编译面**:WebglRenderer/SearchStash 与主线的 session_runtime/fs_edit
   改动在 cargo check 上互相挡编译(各见对方的半成品);契约里「不碰 git」保住了提交隔离,
   但编译验证必须等全部落地后统一跑,中途的绿/红都不可信。
2. **todo 工具的 list 参数会整表标 done**:两次误操作把未完成项全标 X;以对话内真实进度为准,
   todo 污染后立即重建。
3. **edit 工具对未显示行号的强校验**:跨行 PUT(如词典尾部追加)频繁被拒,重读-重发循环;
   尾部追加用 `PUT >$`(文件尾)最稳,或 bash node 脚本批量。
4. **300 行铁则的全链压力**:本批 5 个文件被推超(fs_edit/两语 settings/settingsTypes/settings.test),
   拆分动作(命令层拆 fs_edit_cmds、词典拆 settings3)+ 注释压缩双管;收口前 check:gate 才是终审,
