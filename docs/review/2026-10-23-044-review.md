## P2(当轮修)

- **anim errno 前缀误判「已删除」**(`animProjects.ts` classifyProjectReadError):`includes("os error 2")` 无数字边界,errno 20/21/24/28(ENOTDIR/EISDIR/EMFILE/ENOSPC)的 io Display 全部落 deleted,点「AI 会话」误报「项目已删除」——与本提交「归因不猜」立意直接冲突;同仓 wiki.ts 先例用 `\b` 边界且测试钉了 os error 24 反例。**修**:改 `/(?:os error [23])\b/` 边界匹配,os error 3(Windows 路径缺失,父目录被删)对齐 wiki 先例同归 deleted;补 24/21→io、3→deleted 三例。
- **checkpoints 回落窗深链错位成「批次不存在」**(`CheckpointsPanel.tsx`):stale-while-probing 窗内 state.batches 属回落键(cli),但 BatchListView/ChangesPanel 深链 payload 的 sessionId 仍传现值(tmd),BatchSheetTabContent 冻结键 `useCkptBatches(cwd, sessionId)` 查不到批 → 审阅单渲染「批次不存在或已随会话结束」且不自愈;此路径为回落提交新开(修前窗内空清单无可点行)。**修**:面板算 `listSessionId = staleSessionId ?? sessionId` 下传两消费方——行来自哪份清单就按哪份键开单;写路径不受影响(后端账本 per-cwd 按 `(cwd, batch_id)` 寻址)。
- **files 写闸与读闸等值,CRLF 还原膨胀缝**(`fs_edit.rs`):读闸量磁盘字节、写闸量还原本(`\n`→`\r\n` 每行 +1 字节,最坏翻倍);旧组合 512KB 读/16MB 写有 32 倍余量遮缝,9602b3e1 两闸拉平 100MB 后缝暴露——100MB 级 CRLF 文件「读得开、存不进」且任何编辑都无法保存。**修**:写闸提 200MB(= 2 × 读闸上界)并注释缘由;补超闸拒绝且不落盘测试(闸检查在磁盘 IO 前)。
- **files 100MB 直进 CodeMirror 无渲染护栏**(`FileTabContent.tsx`):旧 512KB 闸事实上是编辑器性能护栏;放宽后 99MB 文本 = Rust 串 + IPC JSON + webview UTF-16(×2)+ CM rope + 保存还原多份拷贝,瞬态逼近 GB 级进 WKWebView。**修**:文本管线加 `EDITOR_OPEN_MAX_CHARS = 8M` 护栏,超限停用内置编辑器并提示外部打开(文件本身仍可读闸内预览/外部编辑),新增键三语对称。

## 不成立(抽样)

- lstart 全等比对跨 locale 把 same 误判 reused:同命令同环境,macOS 实测 LC_TIME 不影响格式,lstart 是进程常量。
- unknown 回落补杀重开复用窗口:成立但为已声明取舍(ponytail 注释),触发路径自相矛盾地窄,风险与修前一致。
- checkpoints 回落展示他账内容=串账复发:回落正是翻沿前已在屏的清单,探测窗有界、首拉入仓即切,写路径 per-cwd 不进 sessionId。
- useSyncExternalStore 快照不稳定/无限重渲染:订阅快照是数值 version,回落分支返回原引用或 EMPTY 常量。
- files 四处大小常量应单源:四条通道各自独立预算,注释已逐处写明脱钩;唯一真实耦合(读写等值)已修。
- 写闸缺下限校验会写坏大文件:write_atomic 整串原子替换,无半写窗口。
- 错误文案改写破坏下游分类:isMissingFileError 按 ENOENT 语义匹配不吃大小文案;anim 归因按形态不按文案。
- Rust 测试写 100MB 真文件拖慢 cargo test:预览测试用 set_len 稀疏文件零写盘;写闸测试闸拒在 IO 前。
- detail 透传泄露绝对路径:std io Display 不携带路径,三处 Rust 错误均为固定中文标签 + io Display。
- anim 同 mtime 双写缓存陈旧/modifiedAt=0 键冻结/软链权限误归 deleted/React 轮询竞态/mock 过拟合:均有据不成立,详见各路评审记录。
