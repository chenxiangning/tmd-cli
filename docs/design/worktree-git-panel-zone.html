交互要点
  • Git 面板顶部新增「工作树」常驻区:主仓 / 当前 / 其他三态卡;每卡 = 路径尾段 + 分支 + 脏净与增删统计 + 动作(终端 / 合并回主仓 / 移除)。现有弹窗降级为「+ 新建」入口。
  • 分支列表从「一锅粥」改为按检出归属分区:主仓检出 / 检出于某 worktree / 未检出。每棵树一棵子列表,一眼看清哪根分支长在哪棵树上。
  • 「未检出」区的行 hover 出现「建 worktree」快捷动作 —— 分支与 worktree 的创建互达。
  • 当前视图所在树高亮;跨树切换 = 点工作树卡(整屏工作区跟随),不必回侧栏。
落地面

Git 面板右栏(GitPanelMain 顶部)插入工作树区;分支列表组件按 worktree list 的 branch 归属重分组。数据面零新增 IPC,全部复用 git_worktree_list 与 git_branches。
