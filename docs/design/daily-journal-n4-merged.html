设计要点

  • 三视图一 tab:「年 / 月 / 轴」segmented 切换同一数据源。年 = 12 宫迷你月(状态点阵 + 节假日红点 + 便签内框,点月下钻);月 = 大格索引卡(文章标题 + 总览首行 + 便签预览 + 引擎点 + 强度条);轴 = 叙事流(脊柱 + 增量珠子 + 折叠日卡 + 「全文」直开文章 tab),迷你月条只在轴视图出现。
  • 详情即文件 tab(弹窗废除):点月格、轴卡「全文」直接以文章 tab 打开完整详情——与文件 tab 同一挂点;总览、分节、生长珠子、便签编辑全部在 tab 内完成(不再有日详情浮层)。空日点月格 = 直开 tab 并自动进入便签编辑态。待生成 / 失败日在 tab 内给出待喂会话清单与重试位。今日蓝描边呼吸;五态日状态机;「补齐待生成」批处理。
  • 每日一篇 AI 汇总文章:一天一篇,总览段 → 分节正文 → 未完事项固定结构;标题由 AI 起草,用作月格标题与轴卡标题。增量只喂新增会话,新内容整理成新节并入(「11:47 并入」留痕章),既有节永不重写;跨零点晚归会话归前一日、由次日增量并入(9月28日「0.2.5 前夜预检」节演示)。
  • 每日便签:日历上任选一天——包括没有任何 AI 会话的空日——写自己的笔记;编辑位 = 文章 tab 内「我的便签」区(多行文本,⌘/Ctrl+回车保存、Esc 取消、⌘V 可贴截图,清空即删)。展示位 = 月格(琥珀描边 + ✎ 首行预览)/ 轴卡(棕节点 + 卡内便签区 + 折叠头首行)/ 迷你条(内框格)/ 年视图(内框点)。便签与 AI 文章独立落盘:重新生成、增量并入都不碰便签;编辑草稿在后台落盘刷新时保留回填。
  • 生成全部后台运行:定时 / 手动 / 增量 / 重试一律进后台任务队列——切换模块、窗口失焦、最小化都不中断,完成自动落盘并刷新日历。工具栏「后台任务」= 统一管理入口:进行中(可打开会话)/ 排队(可取消)/ 完成(可跳文章)/ 失败(可重试)。今日增量检查、跨零点晚归并入都在队列里可见。
  • 生成会话可打开可干涉:文章由一个真实 CLI 会话产出(如 omp)——从任务面板或文章 tab「生成会话」条进入:会话窗以终端 tab 形态展示成文过程(喂入 → 成文 → 落盘),底部输入框随时插话纠正、让它续写更新当日汇总(演示:15:41 手动干涉拆出 ClawHub P1 独立节并落盘)。历史生成会话已收尾,只读深链会话查看器。节假日关联(联网)不变:在线角标 / chip / 红点,离线仅周末底纹保底,状态点如实显示。
  • 扩展位:便签升级 Markdown 渲染 + 便签检索;文章 Markdown 落盘(~/.tmd-cli/daily/YYYY-MM.json,一档一天,便签同档,截图落附件目录);月/年报 = 聚合各篇总览段;「未完事项」接 composer 作次日上下文;生成会话支持换引擎重开、干涉历史回放。
