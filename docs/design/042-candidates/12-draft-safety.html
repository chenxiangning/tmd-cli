交互与实现说明

  • 关窗闸复用关闭协调器:requestCloseAllTabs 增加退出确认模式(tabClose.ts 契约,docs/architecture/24-tab-close-guard.md 扩展纪律),不另造第二套协调器。
  • 聚合弹层 vs 串行逐个问:退出场景聚合一次问清,不串行弹 N 个确认;点「放弃并退出」走强制放行通道绕各 kind 闸(闸只服务单 tab 手势,退出已整体裁决)。
  • localStorage 从不入 settings:取舍先例 = settings 存跨会话配置,localStorage 存草稿/UI 态;镜像键带 tmd. 前缀与既有键族同域,不进设置面板。
  • ssh-file 一并纳入:ssh-file 现无草稿缓存(RemoteFileTab 只有内存 doc,ssh/index.tsx:69 注释自证「远端编辑没有本地草稿缓存」),镜像腿补齐第三 kind,恢复条同款。
  • 脏 tab kind 全仓恰三种:file / ssh-file / journal 文章(updateTab dirty 写点三处文件实证),镜像范围即三 kind,不会溢出到会话/composer 等已持久化草稿。

已有底子:tabClose 协调器+dirty 镜像链+composer localStorage 先例+windowClose 原语。 成本:S-M(⌘Q 腿+小块 Rust)。 风险:「秒关」习惯冲突(不再问 checkbox 缓解);聚合确认与各 kind 闸的双通道要写死(退出走强制放行,单 tab 手势仍过闸)。 验证:关窗弹层 / 崩溃恢复 / 256KB 截断 / TTL 过期 / ⌘W 单关不变五路径各一+真机 ⌘Q 目检(若做 Rust 腿)。
