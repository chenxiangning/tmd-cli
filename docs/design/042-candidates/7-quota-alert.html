交互与实现说明

  • 轮询主体已落地:notify 撞墙预警 0.2.8 起 10min 轮询(commit 8c08a44f),本项是增量三腿,不新增定时器。
  • 结构化下沉:vendors/types.ts 在 balanceText 旁新增 balanceValue(number);只有 deepseek(total_balance)/relay(balanceNum) 透传得出,其余家不填——无余额 ≠ 解析失败,UI 不渲染该行而非显「—」。
  • claude 窗口腿:windowResetFor 迁 cli-shared/quota(welcome 改 import 纯 cutover,零新依赖);notify 侧对 claude 会话尾读推算,resetAt − now < notifyQuotaResetMinutes 报「N 分后重置」。
  • 去重持久化:扩 notify-log.json 头部 quotaSeen(键沿用 pickQuotaWarnings windowKey + 引擎前缀,窗口键自带 resetsAt 天然按周期翻新,余额键用首次越线小时桶),修「重启失忆」;写坏按无记录处理,宁多勿漏。
  • 顺手修真 bug:quota 分支改走 dispatch 同款三闸(NotifyKind 加 "quota"),免打扰窗拦 OS 通知但流水照记——现状 quota 分支绕过 shouldNotify 是缺口。
  • 行为边界:告警不阻塞、不弹打断;阈值改动即时生效;余额阈值 = 0 即关闭余额腿(不发、不写 quotaSeen),窗口腿不受影响;写坏按无记录处理;minimax windows 语义是「剩余」百分比而 QuotaSnapshot usedLabel 恒「已使用」,实现时逐家断言单测钉死口径。
  • 明确不做:新增轮询/提频(10min 轮询是 0.2.8 既有);余额百分比阈值(无额度分母,deepseek/relay 币种与套餐粒度不同,纯属发明数据);凭据懒刷新挂点(只在打开首页时有新数据,不看首页 = 永不告警,主场景失效);预算熔断 / 自动停跑(熔断交给引擎自身);成本估算单价表(不做用量换算,只展示引擎回包口径)。

已有底子:notify 撞墙预警轮询链(0.2.8 起,8c08a44f)+ 阈值键 notifyQuotaWarnPercent + pickQuotaWarnings 去重 + 通知中心流水 + quotaWindow 纯函数(welcome,迁 cli-shared)。成本:低。风险:minimax 窗口「剩余」口径与 usedLabel 不一致(逐家断言钉死);quotaSeen 写坏(按无记录处理,宁多勿漏)。验证:越线 → 通知中心出卡;同窗口二次轮询不重发;重启后仍去重;窗口翻新后可再报;免打扰窗 OS 静+流水记。
