行为边界与明确不做

行为边界

  • 作用域只是过滤器段:引擎 / 时间 chip 行为不变;切「全部」= 遍历 getWorkspaces() 各 root 逐个喂同一 SessionIndexer,不新建第二条索引管线。
  • prime() 剪枝(定稿):cwd 命名空间留存 + 全局条目 LRU 上限 3000 双管齐下——prime 只剪「cwd===本次 && 不在 live 集」的键,超量按最近使用淘汰;纯 LRU 会把本区热缓存挤光(回到互踢),纯命名空间无失控护栏。扫描节奏加 12ms 时间盒排空(缓存命中步连做,真读步维持 60ms 间隔),否则全部态暖缓存也要分钟级。
  • 命中行三 pill:工作区名(deriveWorkspaceName 现成)+ 引擎 + 时间;本工作区态不显示工作区 pill,减少噪音。
  • 失效工作区:root 复核失败的命中标灰 + 「工作区已移走」pill,可看不可跳——点击仅 toast 提示,不跑跳转(定稿:被否「cwd 在就跳」,开出的会话 workspaceId 为空、侧栏永不可见,比不跳更坑)。
  • 扫描节奏:复用 indexerTicks 宏任务切片,逐工作区上报进度「正在扫描 N/M 个工作区」;期间键盘选择不受影响。
  • 键盘契约不变:↑↓ 选择、Enter = 先切工作区(时序桥已有)再 resume + openThenJumpToText 行级定位,Esc 关闭,零新快捷键。
  • 设置口径:零新键——作用域 chip 为浮层局部 state,不持久化,关掉浮层再开回到「本工作区」。

明确不做

  • 助手消息入全局索引:041 已裁决缓行,替身见 041 组页 5(搜索增强);本页只索引会话标题与摘要,口径与现状一致。
  • FTS5 / 倒排 / 向量检索:维持 mtime 缓存懒扫描 + 开浮层 re-prime,不引存储引擎。
  • 定时刷新 / 后台常驻索引:不建后台任务,索引生命周期跟随浮层。
  • 跨工作区合并排序算法:各工作区命中按现有时序归并展示,不做相关性打分。

已有底子:SessionIndexer(引擎无关,mtime 懒扫描)+ SearchOverlay(引擎/时间 chip + ↑↓/Enter/Esc)+ openThenJumpToText 行级定位 + 切工作区时序桥 + deriveWorkspaceName + indexerTicks 宏任务节奏。成本:中。风险:prime() 剪枝改造影响面(已定稿:命名空间留存+LRU 3000,见行为边界);indexer.ts 已 279 行,先拆 searchCore.ts 再动;7+ 工作区首扫时长(时间盒排空兜)。验证:本区/全部双态切换缓存不互踢;跨工作区命中 Enter 后落在正确工作区与行;扫描中输入不卡顿、切回本区即中止;空结果双态文案可区分。
