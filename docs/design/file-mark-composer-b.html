方案 B 取舍

优点标记可管理:列表、勾选、批量、跨文件汇总;代码区永远干净;面板挂在既有右栏 tab 体系(Git/标注),不新增布局概念。
代价多占一栏宽度;标记与代码空间分离,精读时要左右对照;交互链路最长(选 → 面板写 → 勾选 → 发)。
适合评审式通读:先攒一摞标注,再一次发给 AI 集中处理;标记数量多或跨文件的场景。
