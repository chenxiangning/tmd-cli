两方案共同的设计决策

  • 层级收敛为两层:工作区 → 会话。供应商不再是分组维度,退化为行首 14px icon(落地用各 CLI 插件 glyph,原型为字母徽章占位)。

  • 选中态唯一高亮:accent-soft 底 + 2px 左竖条 + 查看中眼睛,整列表只有一行亮 —— 痛点① 的根治。
  • 状态语义保留:6px 圆点(绿呼吸=运行中 / 蓝=未读 / 灰=静止),「等待确认」胶囊不变;时间轴贯穿竖线随扁平化移除。
  • 终端 / SSH 同样平铺:icon 区分会话种类,不再单设分组。
