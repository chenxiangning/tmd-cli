6. 设置 · 行为:假死自证说明文案 D1 附带 · 纯文案(i18n 三语)

render_health 诊断面板补两句说明,让「客户端假死」发作时可自证(看 Rust 日志两行),不用盲猜。零布局变化。

渲染健康自愈
检测到界面冻结时自动按「聚焦窗口 → 重载渲染」阶梯自愈(洪水期只聚焦防回放风暴)。 遇假死可先看日志自证:render_health: 渲染粘死未愈(strikes=…)为自愈在动作, ,洪水期 reload 降级为输出洪水保护,两者都不必手动处理。

7. 多步轮状态稳定性:通知 / 计时 / 未读 / 存证 F · 码(先于 soak)

现状根因:多步 agent 轮里每步落定都触发一次 busy=false(piRpc.ts:244-249),下游消费原始边沿——计时每步归零、OS 通知每步弹一次(真轮末反而哑)、未读按步虚高、checkpoints 只记第一步(后续存证短路)、发送后 getState 超时会把已发出的文本回填草稿。变化:通知 / 计时 / 发送分支 / 未读沿统一改走 turnLive 宽限态边沿,整轮稳态。

现状(三步轮,每步落定都触发一次 busy=false)
step1 产出 working 0:12 → 0:00 ⚡OS 通知 · 未读 +1 step2 产出 working 0:09 → 0:00 ⚡OS 通知 · 未读 +1 step3 产出 working 0:07 → 0:00 ⚡OS 通知 · 未读 +1 轮末:checkpoints 只记 step1(后两步存证短路)· 未读合计 +3 发送后 getState 超时 → 已发出文本被回填草稿,重发即重复消息
变化(同一轮,改走 turnLive 宽限态边沿)
整轮连续计时 working 0:00 → 1:48,不中途归零 轮末:OS 通知恰一次 · 未读恰 +1 · checkpoints 三步全记 发送成功即清草稿,后续 evidence/getState 超时不回滚
同批可见面(F 其余项 + B2/D2 行为修复)
锚点轨:流式期不再每 120ms 重建测量,长会话滚动抖动消失 接力(relay)按钮:挂载早于注册时不再永久灰置,可点击提示 通知点击已关 tab:恢复原会话(resume),不再开全新空会话 手机上传图片:帧体积约 1/3(通道换 base64),大图不再卡顿数秒 幕布尺寸偶发取失败:立即补拉,错误折行窗口从最长 3s 收敛
