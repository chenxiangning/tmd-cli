用量 / 限额重置时间可视化

Quota 面板基于 session JSONL 用量行(sessionUsage.ts,已覆盖 omp/pi/claude/codex)展示用量与重置窗口;claude / codex 可本地推算并标「可推算」,grok / kimi 口径未知,显示「—」不猜测兜底。

Mock · Quota 面板(工作区 ~/code/tmd-cli)

用量与限额 数据源:session JSONL 用量行
倒计时为本地推算,无网络轮询 · 期间建议切 codex 继续工作

交互说明

  • 推算规则:claude 窗口起点由本窗口首条用量行推算;打开面板算一次,本地每分钟重算,点「刷新重算」立即重算——全程读 session JSONL,无网络请求。
  • 窗口起点联动:「窗口起点 HH:MM」= 当前时间 − 剩余时间 + 5 小时窗口,与倒计时同一次渲染、同一份数据反推,每分钟重算时两者同步走针,不会出现起点不变、倒计时在动的漂移。
  • 两个按钮的分工:「刷新重算」= 按当前时间立即重推算(演示无网络重算);「快进到重置(演示)」= 把可推算引擎剩余时间压到 45 秒,归零即见「已重置」终态,再点「恢复初始倒计时」复位,可反复把玩。
  • 可推算标注:claude / codex 卡标蓝「可推算」——用量与时间戳均来自 session JSONL 解析,窗口与重置时间由前端按当前时间本地推算。
  • 灰态卡:grok / kimi 的 reset 语义各家不同且部分无公开口径,面板不编数;hover 灰卡可看原因,且灰态引擎不参与汇总条排序。
  • 倒计时格式:「1小时 18分」,不足 1 小时切分钟粒度;归零后卡片转「已重置」终态(用量清零、pill 转充裕),汇总条自动让位给下一个窗口。
  • 汇总条:取重置时间最早的可推算引擎,「(推算)」标注说明该值为本地推算;灰态引擎不参与排序。
  • 状态着色:充裕 = 绿环、已限额 = 灰环 + 红色强调倒计时;口径未知 = 整卡灰态,与可推算卡明确区分。
  • 数字同源:汇总条、引擎卡、「刷新重算」提示三处倒计时由同一份数据渲染,不会漂移;环形「已用 %」即近 4 窗口迷你条的末位(最近窗口)。
  • 迷你条读数:近 4 窗口迷你条悬停或键盘 Tab 聚焦时浮出「第 N 窗口 · 已用 X%」,不用原生 title(触屏/键盘不可达)。
