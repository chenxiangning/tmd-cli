交互说明

  • 现状:src/plugins/index.ts 的 allPlugins 46 个插件全部静态 import(53 行数组),DesktopApp 单 chunk 实测 3,718KB(gzip 988KB)。
  • 改法:registerTabContent 的 component 用 React.lazy 包裹;插件 activate 分两段——元信息(manifest / 贡献点)启动时常驻注册,重逻辑 activate 首次打开 tab 时加载。
  • 边界:cli-shared 与 kernel 是共享单例,必须保持静态;终端 / xterm 虽是体积大头但常驻首屏,不参与懒加载;真正可懒的是 workbench(19.4k 行)/ anim / git 面板 / files 预览等低频 tab。
  • 配合 Vite 手动分包(vite.config 的 rolldownOptions manualChunks),共享单例与大依赖拆为稳定 chunk,避免懒加载后首包回涨。
  • 命令面板 / 快捷键对未激活插件保持可见:由常驻的元信息贡献,触发时先激活对应插件再执行命令。
  • 点击上表任意带 ▸ 的行可展开 / 收起说明(「工作台」初始收起、「动画」初始展开,即两态小样;切换只是演示态,不影响初始示意);键盘 Tab 聚焦行后按 Enter / 空格等效,再按一次复位。
  • 「必须静态」行不是交互行:悬停或键盘 Tab 聚焦锁图标可看到原因提示——共享单例被全部插件复用,必须随首包常驻。
