暂无批注
悬停 diff 任意行,点行尾「批注」写一条
批注键 = 文件路径 + 行内容哈希,行号漂移不丢批注;回传时拼为结构化消息,走 composer 现有发送路径。
批注生存期 = 会话级,会话结束自动归档、不删除

交互说明

  • 已有能力不重复造:diff 渲染、词级高亮、文件 tab 栏复用 src/plugins/git 现有 CommitDiffTab / DiffTabContent;本候选只新增批注数据层与回传链路。
  • 选中行写批注(新增入口):悬停 diff 任意行(增/删/上下文均可),行尾浮出行内「批注」小按钮;演示中点击即弹出空批注输入态,可添加或取消,添加后落成气泡与右栏卡片;输入态中 Enter 提交、Shift+Enter 换行、Escape 取消(就地编辑同理)。
  • 内容哈希定位,防行号漂移:每条批注的存储键 = 文件路径 + 行内容哈希,不依赖行号;diff 重算后按行内容重新匹配定位,行号变了批注不丢。
  • 双向联动:点右栏卡片滚动定位并高亮 diff 对应行(批注在别的文件时自动切 tab);反向点 diff 上的气泡,也会定位右栏卡片。
  • 编辑与删除(会话级生存期可删):气泡上铅笔可就地编辑(同步右栏卡片),气泡垃圾桶或右栏卡片 × 可单条删除;全部删空时右栏显示空态。
  • 回传走 composer:底部按钮把全部未回传批注拼为结构化消息(文件 + 行内容哈希 + 原话),复用 src/plugins/composer 现有发送路径作为下一条消息;演示中点击后按钮变「已回传」并禁用,批注(气泡与右栏卡片同步)标记已回传;无未回传批注时按钮显示禁用原因;侧栏底部「重置演示」可恢复未回传初始态。
  • 生存期 = 会话级:批注随会话保存,会话结束时归档留存、不删除;归档会话中仍可回看历史批注。
  • 文件维度:顶部 tab 按改动文件切换,徽标 = 该文件未回传批注数(演示:ipc.ts 2 条 + pty_spawn.rs 1 条 = 右栏 3 条);回传按钮作用于会话全部文件的批注,不只是当前 tab。
