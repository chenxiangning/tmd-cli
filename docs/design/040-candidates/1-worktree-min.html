交互说明

  • 管理面已有,本提案只补会话链路:worktree 列表 / 新建 / 移除 / 清理悬空 0.3.x 已落地并继续可用;以下均为「会话 ↔ worktree」增量。
  • 右键会话卡一键起会话:「在新 worktree 中起会话」自动完成新建分支 → 复制工作区 → node_modules 符号链接 → 在新目录拉起会话,原会话不受影响;菜单键盘可达(Tab 进入、↑↓/Home/End 移动、Enter 触发、Escape 关闭)。
  • 分支名预填可改:默认由会话标题生成(冲突追加 -2、-3);可基于 HEAD 或指定分支创建,确认弹层即所见即所得。
  • 弹层实时校验与终态:分支名与已有分支冲突时自动改 -2、-3 并黄字提示,空名/含空格禁用「创建」;点击创建(或输入框内 Enter)后转圈 → 成功终态,worktree 徽标同步出现在 ③ 会话卡;「再来一次」整体复位可反复演示,输入框 Escape 一键清空回预填。
  • 双向关联徽标:会话卡与 worktree 列表行互显同一「worktree · 分支名」徽标,点任一侧跳到对应另一侧;会话结束徽标随之消失。
  • 磁盘占用列为新增:Rust 侧需在现有 porcelain 解析之外新增 walkdir 目录统计(异步 + 缓存),列表按占用排序便于回收决策。
  • 共享省磁盘:node_modules 符号链接指向主工作树,构建缓存走 APFS/btrfs COW;新建 worktree 秒级完成,磁盘增量只有源码本身。
