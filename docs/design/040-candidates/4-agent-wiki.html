交互说明

  • 退出即沉淀:复用 kernel.sessions.exited 事件(autoDistill.ts 同款挂点,记忆沉淀链 d7ca11d 先例),会话退出即触发写入,默认 opt-in;顶栏常显上次写入时间。
  • 生成零模型成本:摘录 = 退出时取会话尾部 N 条 assistant 消息本地截取,不经模型改写、不产生额外调用费用;质量上限见右栏开放问题。
  • 本地存储:工作区目录下 .tmd/wiki.json 本地单文件,无账号体系、无云同步;换机器即换库,可随工作区目录一起备份。页脚 wiki.json 徽标可点,展示同一存储位置。
  • 挂载为子模块:挂在现有 memory-coordinator 插件下(capsule / console / install 之外新增 wiki 子模块),面板入口随插件注册,不是新插件。
  • 来源可回溯:每条记录带 harness 徽标(harnessLabel 映射:pi 显示为 pi/omp,其余原样透传)与日期,hover 浮出「查看来源会话」,键盘 Tab 聚焦条目时同样浮出,点击回跳原始 transcript。
  • 手动沉淀与流转:不等退出,点右上「手动沉淀」对最近会话跑同一套本地截取入库(再点一次演示去重空态);开放问题被回答后移入「已决策」,本页待拍板条目带「拍板」演示按钮可现场移栏,误拍板可点「撤回拍板」回到原位,同主题重复沉淀自动去重。
  • 「今日新增」口径:只统计今日新写入 wiki.json 的条数(退出自动沉淀与手动沉淀均计入);拍板流转 / 撤回只是在栏间移动,不产生写入,数字不变。
