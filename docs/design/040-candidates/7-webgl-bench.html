交互说明

  • 入口:基准页独立于主包、不进 bundle——vite dev 下挂 /bench 路由或独立 html 即可达,应用内无常驻入口。
  • 运行:场景脚本真实执行——cat 10 万行日志、htop 模拟全屏重绘、vim 连续滚屏;每场景采样 10s 取中位数,进度逐行点亮。
  • 判定:中位数 fps 提升 =(WebGL − canvas)/canvas,<5% 视为无感(绿)→ 维持现状;≥5% 可感知(黄)→ 进入按需启用名单;条形长度按差异占比缩放。
  • 依赖决策:基准通过才入 package.json,不预装;addon 未装时由基准页临时引入 @xterm/addon-webgl@6,测完再定去留。
  • 分层落地:不通过 → 不装;通过 → 命中持续重绘的会话按需 import('@xterm/addon-webgl');持续重绘检测命中 → 该会话自动切换,随会话生命周期加载/卸载。
  • 缓存与复测:报告按机型 + xterm 版本缓存,升级 xterm 或换机后状态变「环境已变化」并提示复测;「复测」重跑全部场景覆盖旧报告,旧值保留为对比基线。
