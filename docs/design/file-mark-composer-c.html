方案 C 取舍

优点最短路径:选 → 点 → 发,两步完成;零常驻 UI、零状态管理负担;与既有 composer 附件体系同构(引用就是一种附件)。
代价没有「未发送的标注」可管理:关掉 composer 引用就没了,无法攒一批再发,也无法事后复查「我标过哪些地方」。
适合即兴提问:看到问题立即圈给 AI,不打算留存批注的轻量场景。
