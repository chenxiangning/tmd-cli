方案 A 取舍

优点所见即所得:代码、批注、发送状态同屏;不新增任何面板,学习成本最低;锚点编号让 AI 回复可以精确指认(「① 确实没 clear」)。
代价标记多时行间卡片挤占代码视野(需折叠态:只留旗标,点击展开);批注卡与 diff/大纲等既有行间元素要排优先级。
适合「看一处问一处」的精读式提问;标记数量少(≤5)的常态场景。
