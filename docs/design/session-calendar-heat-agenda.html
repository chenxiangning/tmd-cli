设计要点

  • 月历 = 量化层:热力色深 = 当日 token(sqrt 分级,当月最大值归一),格底 3 点 = 主引擎,角标 = 会话数;右上玫红点 = 当日存在「结束-未查看」会话(治理注意力入口);今天描边、未来日淡化不可点。
  • 生命周期五态(纳入管理):运行中(绿·呼吸)→ 空闲(灰)→ 结束-未查看(玫红·呼吸,点击查看)→ 结束-已查看(浅灰)→ 已归档(默认自动:已查看即归档,无需手动);未查看/已查看态 chip 悬停出流转说明,日头常驻规则条「已查看 → 自动归档」。
  • 状态过滤:工具栏「状态」chips 与引擎 chips 同构,热力月历 + 泳道时间线 + 节律条随筛选即时重算;关掉「已归档」即可聚焦在途会话。
  • 重命名入口:卡悬停出「✎」,点击后标题原位变输入框,Enter/失焦提交、Esc 取消,提交后保持滚动位置。
  • 大视图 = 泳道时间线:左侧共享小时时轨(只列有会话的时段,组头 = HH:00 + 当日该时总会话数/token)+ 五态垂直泳道按小时分带对齐——同一小时带横跨五列,列内该时无会话则留空,跨列时序可直接横读;列头 sticky(状态点+名、N·token、折叠箭头),「已查看」列头内联玫红规则「→ 自动归档」;卡片 [时刻 引擎 / 标题(两行截断) / 工作区 · 指标],引擎色左边条,已归档置灰;单击「未查看」卡 = 查看并移入「已查看」列(同时带内换位)。
  • 交互契约:点格开大视图、← → 逐日、Esc 收起;列头点击折叠/展开(跨日保持,折叠列各时带留空);节律条点段滚到对应时带并高亮该时全部会话卡,悬停卡反标节律段。
  • 落地注:新增数据字段仅两个——会话 `st`(五态)与 `title` 可写(重命名落盘到各家 session 元数据或宿主侧 alias 表);「已查看 → 自动归档」为默认策略,可在设置里留开关。
