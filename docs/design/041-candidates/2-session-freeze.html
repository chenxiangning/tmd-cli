交互与实现说明

  • 插入点唯一:MainPanel kept map 的挤除路径——卸载前把已算出的 buildReseedScreen 结果存进会话级 LRU 冻结存档;重开会话时 TerminalView 挂载流先查存档。
  • 失败即回落:存档缺失或几何不符(cols/rows 变了)→ 回落现状全量回放,零行为劣化;快照只保「屏上状态」,滚出屏的历史本来就走 pager,语义无损。
  • ask 采样不受影响:后台采样由 headless 镜像接管,不依赖幕布挂载;reseedScreenMirror 卸载时序(feed 互斥)原样保留。
  • 栏折叠/最大化不动:栏折叠 = 整条不渲染但 kept 集照旧;最大化 = 纯样式零宽折叠——两者的「永不卸载」纪律与本项正交。
  • 重载恢复:冻结存档是纯内存,⌘R 后全部回落现状路径(readopt 磁盘尾恢复链兜底),不做持久化。

已有底子:buildReseedScreen(卸载时已在算)+ outputBuffers 精确字节尾 + session_history_page 512KB 分页 + terminalReplay 静默撤罩判据 + sessionTabsMax 设置。成本:中(v1 估中-高,深化后下调——新写的只有存档 LRU 与重开分流)。风险:幕布是回归敏感区,五个状态对逐条冒烟是硬要求。验证:造 5+ 会话挤除,重开最旧会话对比现状遮罩时长与首屏内容;terminalReplay 测试链补快照路径用例。
