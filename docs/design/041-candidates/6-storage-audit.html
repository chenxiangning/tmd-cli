  • 体检命令是本项唯一的 Rust 新增:fs 原语清单核实无 size/stat;配方照抄 git_worktree_disk_usage 的 dir_size(手写递归、跳 .git、不跟符号链接、spawn_blocking、有单测),扩成分桶返回。
  • 清理白名单默认全关:checkpoints 用现成 checkpoint_prune(账本 rewrite + 清悬空 states/孤儿对象,零新删除逻辑);docgen 已归档版本链走 fsRemovePath(removeEntryDir 先例)。
  • 两段确认组合:行首击展开明细卡(ConfirmCard 先例:风险说明 + 可反悔提示)+ 3s 无操作武装回弹(marketInstalledRow 先例)——误删三道闸的最后一块。
  • 红线:各家 CLI 会话目录只报告不代删(会话生命周期归各家 CLI);.tmd 只读;磁盘数字仅供决策,无自动清理。
  • 与候选 1 分工:保留律管列表呈现与归档;本项管磁盘占用与白名单清理,条数联动不重复检测。

已有底子:dir_size 配方与单测 + checkpoint_prune 现成命令 + docgen removeEntryDir + ConfirmCard/武装回弹两个确认先例 + registerSettingsSection 注册面 + isDiskSessionEmpty 条数联动。成本:中(体检命令 + 分区 UI;清理面是组装)。风险:误删——白名单默认全关 + 明细二次确认 + CLI 目录零触碰三道闸。验证:体检数字与 du 对账;prune 后 checkpoint_list 一致性(既有测试链)。
