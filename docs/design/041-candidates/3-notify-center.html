交互与实现说明

  • 事件源零新增:三类内核信号 + 额度预警同池入流水;流水写挂三处 dispatch 调用点旁,不动 OS 触发逻辑。
  • 持久化:~/.tmd-cli/notify-log.json(通知是全局语义,不进工作区 .tmd);wiki 同款 {version,entries},坏 JSON 解析为空文档不抛;过期用「追加时顺带过滤」省掉定时器,条数上限兜底。
  • 回跳:流水条目点击 = 与 OS 通知点击同一路径(sessionViewRequested + setActiveSession);该 topic 全库纪律是仅用户手势,消费方幂等。
  • 聚焦补扫先例照用:失焦期间漏掉的 ask 已有 onBlur 补扫账(onFocus 清账),流水同样受益。
  • 手机不联动:首版桌面独立流水,手机树独立无 OS 通知,不双写。

已有底子:notify 三事件 + quotaWatch + registerFilePanel(10+ 先例)+ wiki 本地 JSON 读写模式 + sessionViewRequested 用户手势语义。成本:低-中。风险:免打扰与既有 per-开关声音布尔的口径叠加要在设置页讲清;流水体积双闸(7 天 + 条数)可控。验证:行为矩阵四象限 × 三通道逐格测;坏 JSON / 磁盘只读两个失败路径各一。
