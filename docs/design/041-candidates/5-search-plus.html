交互与实现说明

  • 时间过滤是纯检索期谓词:索引缓存键只有 path→mtime,过滤不动索引循环——加 chip 零额外扫描成本,静态枚举比引擎 chip(动态生成)更简单。
  • 定位的映射键现成:命中消息就是 CliUserMessage.text 同源(userMessages.ts 提取),构造 UserMessageAnchor 无需新数据;jumpToAnchor 的梯队匹配 + 12 页回溯是批注揭示/锚点栏在用的同一条路。
  • 磁盘会话也能跳(v1 说不能,修正):openDiskSession = resume spawn,完成后即有 handle——只是要等 handle 注册(晚于激活),等 terminalRegistryVersion 或事件是唯一接线点。
  • 失败降级如实:定位失败红色闪烁(AnchorRail/TimelinePanel 同款 miss 语义)+ 提示手动定位,不做模糊猜测。
移出本批:助手消息入索引——userMessages.ts 五种行型解析器只产 user 行,assistant 行需逐家新写解析器(claude 的 model 判别是唯一现成注释),且索引缓存 value 形状变化要加版本戳,否则旧缓存永远命中旧值。如要做,单独立项。

已有底子:SessionIndexer/searchSessions(谓词挂点 indexer.ts:189)+ 引擎 chip 模式 + openDiskSession(resume 单例闸)+ jumpToAnchor 梯队与逐页回溯 + miss 闪烁语义。成本:低-中。风险:handle 就绪时序(唯一接线点);超长 needle 梯队 miss(fallback 已有)。验证:活会话滚出屏 / 磁盘 resume / 超 12 页三场景各一 + miss 降级路径。
