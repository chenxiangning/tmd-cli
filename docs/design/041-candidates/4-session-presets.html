交互与实现说明

  • 两步管线是定稿关键:prompt 不进 spawn spec——spawn 成功后 setPendingPrompt / setPendingRefs 经 pending 队列在会话就绪后注入(anim 已趟平时序,照抄即免踩「就绪前用户手动输入」的竞争)。
  • 预设实体:~/.tmd/session-presets.json(agents.json 同款:单文件 + 模块级内存单源 + emit);字段 = 名称/引擎+模型/范围/初始提示词(三元组引用或内联)。
  • identityTrack 必开:真 CLI 引擎 spawn 前快照 listSessions、spawn 后绑定磁盘身份——不开则时间线/审批线全盲(内核契约,非可选项)。
  • 入口与契约测试:工作区右键段恒显(空工作区可达,发现性优先,worktree 入口先例)+ 会话右键「以此预设起新会话」(onDelete 缺省隐藏模式);补 entryContract 同款测试钉「恒显」。
  • 软失效:预设引用的工作区 id 消费时以 root 复核(wtSessionOf 先例),失效标灰;库条目悬空在编辑面板改绑或转内联。

已有底子:spawnRawSession + anim startSession 两步管线(纯 DI 可 node 测试)+ 提示词库(promptStore 三元组身份)+ worktree 分支递增/里程碑回滚 + defaultEngineCandidates + entryContract 恒显先例。成本:低-中。风险:pending 注入时序(anim 已趟);三元组悬空的改绑体验。验证:预设 → worktree 会话 → 时间线/审批线可见;中途取消不残留桩;库条目删除后预设悬空标注。
