与方案 A 的差异 / 代价

  • 直击痛点:「多会话并行分不清窗体」要的是跨会话总览 —— A 只能逐窗聚焦后看;B 的工作区态一屏扫全部。
  • 语义更干净:审批线保持纯批次语义(审批/回退),消息流不混进去;时间线是自己的面板插件(如 session-timeline),经 activate(ctx) 注册面板,合规。
  • 点击闭环升级:非当前会话条目 = 激活该会话 tab(trackOpen 已有)→ 再 anchorJump 定位扎点;当前会话条目与 A 一致。
  • 代价 1:多占一个面板位(顶栏右区 panel-tabs 多一个图标);审批线与时间线不能同屏。
  • 代价 2:工作区态几乎必须做 JSONL 历史回补(否则只能看本次运行期发过消息的会话),依赖各 CLI 插件适配器;缺适配的会话只显示运行期数据,不猜。
  • 本会话态 = A 的紧凑版(单行截断,点行展开全文 + 附件),两态共用条目组件。
