落地要点(与现有体系的咬合)

  • 数据源零新增:kernel 已在广播 kernel.sessions.prompt(PromptSentEvent:sessionId + 原文),checkpoints 插件本就在听 —— 时间线与批次同生命周期(会话级),不需要新 IPC。
  • 历史回补:事件流只管 app 运行期;重启后从各 CLI 会话 JSONL 回补用户消息 —— 必须走该 CLI 插件声明的适配器(cli-shared 铁律:内核不猜私有格式),缺适配的引擎显示 —。可作二期,一期只收运行期消息。
  • 附件渲染全复用:图片 = extractPromptImages + PromptImages(@path token 剥离、96×72 缩略图、lightbox);非图片 @路径同族正则剥成文件 chip。
  • 闭环 = 扎点常驻化:点条目 → 复用 anchorJump 把终端幕布滚到该消息扎点;幕布不切形态也能先读时间线。
  • 摘要行语义切换:审批线态右侧「待审 N」,时间线态「N 条」;segmented 对齐设置页先例(极简展示开关)。
  • 边界:仍只绑当前活跃会话 —— 「别的窗体在干什么」要逐个聚焦看;跨会话总览见方案 B。
